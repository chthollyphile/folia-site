# 设置说明

本页按 **Folia v0.7.22** 的设置页编写。从 v0.7.21 起，设置页按用途分成 `界面`、`音乐`、`应用`、`高级` 四组，每组下面是几个页面，一个页面只管一件事。旧版的`视觉设置`、`界面设置`、`实验室`等页面已经拆散到下面各页里，对照表见文末的[旧版设置去哪了](#旧版设置去哪了)。

如果你现在最需要的是“这个开关到底在界面的哪里”，可以配合阅读 [功能地图与 GUI 位置](/guide/feature-map)。

## 设置入口

- Bravais 资料库：首页中央信息条底部的齿轮。
- 经典网格：主页左上角的设置图标。
- 任意界面：命令面板（`Ctrl/Cmd + K`）搜索设置项的名字，例如`缓存上限`、`全局快捷键`、`歌词过滤`，可以直接跳到那一行。

设置弹窗顶部有两个一级标签：

- `帮助`：快捷键、用户指引、版本信息、AI 求助提示词。
- `选项`：真正的设置中心，下面说的都在这里。

`选项` 左侧是分组导航，顶部有搜索框。搜索不只找页面名，也能找到页面里的分组和单个选项，还认得拼音和常用别名。

| 分组 | 页面 |
| --- | --- |
| 界面 | 外观、播放页、主页与歌单 |
| 音乐 | 播放控制、歌词 |
| 应用 | 通用、快捷操作、连接与集成、存储与备份、桌面（仅桌面版）、性能与动效 |
| 高级 | 模组（仅桌面版）、开发者 |

桌面版和 Web 版共用大部分设置。只在桌面版出现的有：`桌面`、`模组` 两个整页，以及 AI 主题设置、更新检查、全局快捷键、OBS 浏览器源、歌词接口、Discord 播放状态、缓存目录与缓存上限、后台节流、渲染显卡等单项。

## 界面

### 外观

**歌词动画**

- 歌词动画样式：点开进入歌词动画实验台，选择播放页用的模式并逐项调参。当前有`静止`、`流光`、`心象`、`云阶`、`浮名`、`莫奈`、`群唱`、`倾诉`、`回环`、`镜台`、`时计`、`商籁`、`凝彩`、`绘光`、`花火`等模式。
- 随机：在样式选择里选`随机`，勾选几种或全部内建样式组成随机池，每首歌换一种，不会连着重复，每种样式用它自己保存的参数。播放面板上可以给这首歌重抽一种或改随机池。随机池会跟着配置导入导出和同步。
- 智能动感模式（桌面版，需要 WebGPU）的总开关在歌词样式窗口的`全局`页，可选`只用已分析`一档。

逐项参数的含义见 [歌词动画参数说明](/guide/lyrics-animation-tuning)。

**主题**

- 明暗模式：`浅色` / `深色` / `跟随系统`。手动选浅色或深色后不再跟随系统。
- 配色主题预设：`墨染 / 素白`（内置默认）或`自定义`。还没保存过自定义主题时，`自定义`不可选。
- 打开主题乐园：进入完整的主题编辑器，编辑明暗双主题的颜色。

**歌曲主题**

- 主题自动切换：切到一首生成过 AI 主题的歌时，自动应用它的主题。
- 自动为播放歌曲进行主题生成：在自动切换下面。歌曲没有缓存主题时自动生成并应用。用 AI 推断时会产生较高的 token 费用。
- 主题生成来源：`AI 推断`（由 AI 读歌词推断情绪配色，需要配置 API 密钥）或`封面取色`（直接从封面颜色生成，不需要密钥，但配色表现力和属性较少）。没配置密钥时 `AI 推断` 不可选，会给出去配置的按钮。
- 优先使用自定义主题：开启后关闭歌曲主题自动切换，始终用你保存的自定义主题。

**AI 主题设置**（仅桌面版）

- AI 供应商：直接选服务商，可选 Gemini、DeepSeek、小米 MiMo、阿里云 Qwen、腾讯云 TokenHub、OpenAI、Anthropic、Kimi、智谱 GLM，或自定义兼容接口。有的服务商还要选`站点`。
- 密钥：内置服务商不用填接口地址，填好密钥就能获取模型列表，从下拉框里选模型，并会预填推荐模型。自定义兼容接口需要自己填接口地址和模型。
- 思考、温度等参数按服务商和模型自动处理；用到已停用的模型时会提示。
- 流式传输：只在服务商要求流式时开启，结果仍然在完整接收后才解析。
- 为 AI 使用系统代理：只让 AI 相关的请求走系统代理，不影响播放。
- 测试连接：保存前可以先测一下。

密钥用系统安全存储加密保存，保存后不再回显，清除用单独的按钮。

### 播放页

**视图**

- 播放后进入的视图：点击播放后默认打开哪个视图，可选`可视化`（播放页）、`Lattice（队列拼贴）`或`留在原处`。首次使用时 Folia 会问一次。私人 FM 不支持 Lattice，启动私人 FM 时仍进入标准播放器。详见 [Lattice](/guide/lattice)。
- 边缘暗角：在队列拼贴与资料库墙四周加一层淡淡的暗角，让视线落在中间。
- 海报聚焦叠色：给普通海报加颜色叠层，突出正在播放、聚焦或悬停的海报。可以强制使用自定义颜色，并调叠层颜色和叠色强度。

**控制栏**

- 自动隐藏控制栏：自动收起播放页的进度条和右侧按钮。
- 同时隐藏鼠标指针：控制栏收起时指针一起消失，移动鼠标即可唤回。
- 空闲时隐藏鼠标指针：鼠标静止一段时间后隐藏指针，控制栏保持显示。
- 底部组件高度：统一调整各页面的底部控制条、歌曲卡片、操作按钮和侧边面板的高度，播放页字幕也跟着走，最高不超过半个屏幕。也可以在播放页上直接拖动调整。
- 进度条右侧按钮：自定义进度条右侧的两个按钮，默认是`循环模式`和`歌词时间轴`，也可以换成上一首、下一首、随机队列、喜爱、音量、播放队列、播放队列（海报）、睡眠定时或定位正在播放的歌。这两个按钮同时决定 Lattice 展开卡片上中间两个按钮的功能。

**歌曲信息卡片**

播放器和播放队列左下角的“正在播放”卡片：

- 显示方式：`限时显示` / `常驻显示` / `不显示`。
- 显示时长：限时显示时停留多久。
- 在首页显示：关闭时只在播放器和播放队列出现。资料库界面是 Bravais 时，墙上始终显示。
- 显示信息卡片关闭按钮：卡片打开后在右下角显示浮动关闭按钮。

**视频层**

- 在歌词后方显示视频：在背景和歌词之间播放静音视频，跟着播放、暂停和跳转同步。
- 本地视频优先于视频 URL，重启后自动恢复所选视频；还可以调不透明度和填充方式。
- 视频层不参与视觉配置的导入导出，也不在 OBS 源中显示。

**播放页界面**

- 隐藏底部控制条
- 隐藏底部字幕层：不影响使用独立字幕的动画模式。
- 隐藏右侧按钮：隐藏后仍可用 `P` 键开关右侧面板。
- 始终显示播放页左上角返回按钮
- 始终显示切歌按钮：让进度条标题两侧的上一首 / 下一首箭头常驻，不用悬停才浮出。

这些选项适合录屏、投屏、桌面叠加或装饰性的播放窗口。

### 主页与歌单

- 资料库界面：首页、集合与歌手页用哪套界面浏览，`Bravais 墙面`或经典网格。切换时保留筛选、选中项和播放队列。
- **Bravais 墙面**（使用 Bravais 时出现）：透光、每块窗数、集合叠页边、信息条方向（自动 / 竖向 / 横向）、信息条始终透明、信息条样式、墙后画面显示歌词、墙后画面模糊。实际截图见 [Bravais 外观设置](/guide/bravais#调整墙面外观)。
- **主页**
  - 顶部胶囊入口：决定首页顶部显示`歌单`、`电台`、`探索`、`专辑`、`本地`中的哪几个。
  - 歌单卡片样式：`纯图片封面`或`拍立得卡片`。
  - 记住主页卡片位置：切换顶部入口或从播放页返回时，回到各入口上次浏览的卡片。位置只在本次打开应用期间保留。
- **网格卡片**：命令面板搜索`网格卡片外观`可以直接打开带滑块的调节界面。
  - 全画幅封面：封面铺满整张卡片，歌名和歌手叠在封面上的渐变遮罩里，做法和队列拼贴一致。
  - 正方形卡片：只在全画幅封面开启时可用。卡片高宽相等，方形封面完整显示；卡片面积不变，变矮的同时会变宽。
  - 卡片最小尺寸、卡片最小透明度：远离中心的卡片最多缩小、淡出到多少。旁边有恢复默认的按钮。

## 音乐

### 播放控制

**Folia 智能过渡**

- 过渡：总开关。
- 过渡模式：`Folia Crossfade`（固定的淡出淡入）或 `Folia Automix`（分析相邻歌曲后自动混音）。分析用到的模型随安装包附带，不用另外下载。
- 过渡最长时长：只在 Crossfade 模式下出现；Automix 自己决定每次过渡多长。
- 表现模式：更激进的过渡表现。
- 过渡动画：用`屏幕圆环`（画在屏幕正中，按任意键消失）或`卡片描边`（画在歌曲信息卡片的边框上）显示过渡进度；短于 5 秒的过渡不显示。

歌曲缓存关闭时，在线歌曲不会被提前分析，Automix 效果会明显下降，页面上会提示。本地和 Navidrome 的歌也会做过渡分析。完整说明见 [Folia 智能过渡](/guide/automix)。

**声音与设备**

- 当前播放声卡：切换音频输出设备，或跟随系统默认。桌面版优先支持；浏览器只有支持 `setSinkId` 时才能切换。
- ReplayGain 模式（响度平衡）：检测到增益数据时，按单曲或专辑统一播放响度。
- 暂停/播放淡入淡出：暂停前淡出，恢复时淡入。
- 自动转换无法播放的音频（仅桌面版）：遇到 Chromium 解不了的本地或 Navidrome 歌曲时，用内置 FFmpeg 转换后接着播放，不修改原文件。转换结果进缓存目录，Automix 也会分析转换后的音频。

**播放行为**

- 加入队列的默认位置：`追加到末尾`或`追加到下一首`。经常边听边插歌的话，建议选`追加到下一首`。
- 无法播放时自动跳过（默认关闭）：歌曲需要会员或购买、只能试听、所在地区不可播放，或原因不明无法播放时，倒计时后跳到下一首。需要登录的歌和网络问题不跳过。
- 播放时阻止休眠（仅桌面版）：播放期间保持显示器唤醒。
- 语音输入时暂停播放（仅 Windows 桌面版）：检测到语音输入或麦克风被占用时暂停，结束后恢复。

**音频效果器**

音频效果器不在设置页里，而是从播放页右侧面板`控制`标签的音量行按钮打开，也可以在命令面板搜索`音频效果器`或 `eq`。

- 频段增益：十段均衡器，内置`水平`、`Lo-Fi`、`收音机`、`大厅`、`人声`、`低音增强`几个预设，另有两个自定义栏位。
- 效果链：在频段处理之后串接的后处理效果，包括`低频截止`、`高频截止`、`饱和失真`、`比特降质`、`抖晃`、`黑胶噪声`、`立体声宽度`、`空间混响`、`动态压缩`。

命令面板里也能直接切换预设，或用`水平`一键清空均衡器和所有效果。模组改过均衡器时，可以用命令`音效：换回我的音效`回到自己的设置。

### 歌词

**歌词来源**

- 自动使用最佳歌词：自动检索网易云、AMLLDB、QQ 和酷狗歌词，有完美匹配的逐字歌词时优先采用。
- 歌词匹配优先级：多个歌词源都有高置信度匹配时，优先用哪一个来源。
- 本地歌曲歌词优先级：本地歌曲同时有在线匹配的歌词时，选`本地歌词`还是`在线优先`。手动指定的歌词来源不受影响。

**时间与过滤**

- 全局时间偏移：为这台设备上的所有歌曲整体平移歌词时间轴，补偿蓝牙等输出延迟。点开后可以在实时预览里微调。
- 歌词过滤：点开后设置逐行过滤规则和开头制作人员信息的处理，命令面板搜索`歌词过滤`可以直达。

::: tip 全局偏移和单曲偏移的区别
全局时间偏移作用于这台设备上的所有歌曲，适合补偿固定的输出延迟；某一首歌自身对不齐时，仍然应该用歌词面板里的单曲偏移。
:::

**歌词过滤的两部分**

逐行过滤：

- 启用逐行过滤：开关。
- 正则表达式：按整首歌的正文歌词逐行匹配，命中的整行会被删除。
- 面板里可以直接预览当前歌曲的过滤结果，显示`已过滤 N / 总计 M`。
- 关闭开关不会清空写好的正则，下次开启时还在。

开头制作人员信息：识别歌词开头的署名块（作词、作曲、编曲这一段），处理方式三选一：

| 处理方式 | 行为 |
| --- | --- |
| 始终显示 | 完全按歌词文件里的时间轴显示 |
| 按前奏长度 | 前奏够长就显示（必要时摊开到整段前奏），不够就整块隐藏 |
| 始终隐藏 | 总是去掉开头的署名块 |

配套选项：

- 每行最少停留：判断“够不够长”的单行最低持续时间。
- 吸收相邻行：`关闭` / `向前吸收` / `前后吸收`。开启后，署名块相邻、单行耗时短于上面阈值的行一起并入块处理。
- 自定义识别规则：留空用内置署名词表；填写后整体替换内置规则，但仍然只作用于开头那一块。
- 面板会实时显示`当前歌曲的判定`：识别到几条署名、前奏多少秒、完整显示需要多少秒。

命令面板里也有`开头制作人员信息`、`开头制作人员信息：吸收相邻行`两条命令，按一次轮换一档。

**本地歌词文件格式优先级**

同一首本地歌曲有多个同名歌词文件时，按这里拖动排好的顺序选用；`.fia` 始终最优先。

## 应用

### 通用

- 界面语言：`跟随系统`、`简体中文`、`繁体中文`、`English`、`Indonesian`。
- **启动与窗口**
  - 进入应用后自动播放：打开应用时续播上次的歌。桌面端和已安装的 PWA 可直接起播；普通浏览器标签页可能被自动播放策略拦下，需要先点一次页面。
  - 启动后直接进入播放界面（仅桌面版）：跟随`播放后进入的视图`，选了 Lattice 时启动后进入队列拼贴。
  - 始终显示标题栏控制按钮：让最小化、最大化和关闭按钮保持显示，但不显示整条标题栏。
- **更新检查**（仅桌面版）
  - 启用更新检查：启动时检查 GitHub Releases。
  - 启用自动更新：发现新版本后自动下载，需要能直连 GitHub。
  - 更新通道：`Realeco · 正式版`、`Limo · Nightly`、`Cielo · Canary`；自行构建的版本显示为`内部构建`，不支持自动更新。通道差异见 [桌面版功能](/guide/desktop)。
  - 平台差异：Windows 支持自动更新；macOS 与 Linux 会检查并提示，但需要手动下载完整安装包覆盖，或用包管理器（Arch 用户可走 AUR）升级。
- **思索教程提示**
  - 思索教程提示：指针停在可教学的控件上时提示长按 G，可选`始终显示`、`仅未看过的区域`、`关闭`。
  - 触屏思索按钮：触屏设备右上角的灯泡。

### 快捷操作

- **全局快捷键**（仅桌面版）：Folia 在后台时也能按的快捷键。修饰键固定为 `Ctrl+Alt+Shift`（macOS 上是 `Control+Option+Shift`），你只选最后一个键（A–Z 或 0–9），再给每个快捷键选要运行的命令：播放/暂停、上一首、下一首、音量加减、静音、循环、随机，以及模组提供的命令。被别的程序占用、和另一个全局快捷键重复的组合会在对应行标出。
  - 原生 Wayland 下改为`注册到桌面环境`：Folia 把整组命令交给桌面环境，再按桌面环境的说明为每一项绑定按键。
  - 绑定的模组命令在模组停用时保留，模组重新启用后按键自动恢复。
- **命令窗口**
  - 快捷命令：最多三个命令固定显示在命令面板下方。
  - 自定义快捷键：把一个在任何界面都可用的命令绑定到 <kbd>Alt</kbd> + `A–Z` 中的一个字母；与已占用的键冲突时会被拒绝。
- **海报墙**
  - 向左滑动打开：海报墙右下角按钮向左滑动时打开`过滤搜索`还是`命令窗口`；点击仍然打开歌曲列表。Lattice 里的同一个按钮也一样。
  - 海报墙上用 S 键打开命令窗口：默认关闭，此时首页网格上的任意单字符（含 <kbd>S</kbd>）都进筛选框；打开后 <kbd>S</kbd> 改为打开命令窗口。只影响首页网格，播放页和 Lattice 里 <kbd>S</kbd> 本来就能直接打开。

命令搜索、队列批量语法、执行模式等完整说明见 [命令面板用户指南](/guide/command-palette)。

### 连接与集成

**服务**

- Navidrome：保存服务器地址、用户名和密码，并提供连接测试。Folia 走标准的 **Subsonic / OpenSubsonic API**，能连的不只是 Navidrome。连接成功后会显示服务端类型、版本、OpenSubsonic 是否可用、支持哪些扩展，以及这个账号能访问哪些音乐库；排查问题时先看这块。Docker 部署预置了服务器时，可以一键恢复预置配置。完整说明见 [Navidrome / OpenSubsonic](/guide/navidrome)。
- 同步服务：用你自己的服务器（Cloudflare D1 Worker 或自托管服务）同步外观设置与 AI 主题。填 Sync Server 地址和 Bearer Token（就是服务端配置的 `SYNC_TOKEN`），可以先点`测试`；还能选是否同步视觉设置、手动立即同步，以及导出 / 导入整库 zip。导入会覆盖本地同步缓存，已启用同步时还会推送到服务端。服务端部署见 [部署同步服务](/guide/deploy-sync)。
- Discord 播放状态（仅桌面版）：在 Discord 桌面端显示 Folia 正在播放的歌，旁边显示连接状态。
- 上报播放记录（仅网易云）：在线网易云歌曲听满 30 秒后，向你的网易云账号上报一次听歌记录，需要先登录。本地文件、云盘歌曲和其他平台不上报。这会写入你的真实账号、用于网易云的推荐计算，有一定风险，默认关闭。

**直播与舞台**

- 播放页透明背景：把播放页换成透明窗口，适合 OBS 浏览器源或抠像叠加。
- OBS 浏览器源（仅桌面版）：提供一个本机地址和 Token，让 OBS 以浏览器源接入 Folia 的完整歌词动画，不播放音频。页面会显示连接数，可以复制地址、复制 OBS CSS、重新生成 Token（旧地址随即失效），并选 OBS 主题是`纯静态`、`动态·内置`还是`动态·AI`。页面里有分步的使用说明。
- OBS 连接时保持主窗口动画（仅桌面版）：默认在 OBS 连上后主窗口停掉重动画；打开后两边同时渲染，占用更多 GPU / CPU。
- 歌词接口（仅桌面版）：在 `http://127.0.0.1:32109/v1/lyric` 提供无需鉴权的只读歌词接口，只监听本机。页面显示接口地址和`运行中` / `不可用`，端口被占用时显示不可用。omarchy / quickshell 用户可以直接用顶栏歌词插件 [lia.lines](https://github.com/chthollyphile/lia.lines)，自己对接见 [歌词接口文档](/developer/lyric-api)。
- 舞台模式：桌面版开放本机 HTTP 接口（Stage API），供外部程序读取或推送播放、歌词与点歌；Web 版开启后首页出现舞台入口，歌词来自本机服务。
  - 舞台数据来源：Stage API、Now Playing（固定连接 `ws://localhost:9863/api/ws/lyric`，需要先在本机启动 now-playing 服务）或 Nexus PlayerCap。
  - Nexus PlayerCap：地址留空用本机 `localhost:8765`，可以选跟随的播放器、时间轴基准，以及是否忽略播放器清除（暂停、空闲、关窗时保留歌词，换播放器才刷新）。
  - 开启 Stage API 后显示本机地址和 Bearer Token，可以重新生成 Token。

完整接口说明见 [Stage API](/developer/stage-api) 和 [Stage 与 Now Playing](/guide/stage-and-now-playing)。

### 存储与备份

**媒体缓存**

- 缓存歌曲：缓存音频以便离线收听，混音过渡也能提前分析下一首。
- 缓存目录（仅桌面版）：指定大体积缓存文件写到哪里。
- 缓存上限（仅桌面版）：超过上限后，最久没听的歌先被删掉；可选`不限制`。

**缓存详情**

分类显示`歌单数据`、`歌词`、`封面`、`媒体文件`、`分析数据`的占用，每项都能单独清理，也可以`清空所有`。这里还有本机缓存歌词的批量导出入口。

**本地文件夹监视**

- 自动扫描已导入文件夹：监视导入过的本地文件夹，文件增删改时自动做一次增量扫描。**默认关闭。**
- 下方逐个列出已导入的文件夹和监视状态：`正在监视`、`只监视这一层`、`正在扫描`、`监视失败`、`访问权限已失效`，以及上次自动扫描的时间；`重新检查文件夹`立刻跑一次检查。
- 部分环境（受浏览器 / 系统 API 限制）只能监视文件夹本层，子文件夹的变化发现不了，状态里会写明。访问权限失效时需要重新导入这个文件夹。

**备份与导入**

- 导出视觉配置：可以复制为标准 JSON，或复制 `folia-theme` 文本配置码。`复制配置码时包含的主题`决定配置码里带`AI 主题`、`自定义主题`还是`不包含主题`。
- 导入配置：粘贴 JSON 或配置码导入。

适合备份主题、跨设备迁移，或把一套歌词动画调参分享给别人。多端自动同步在 [连接与集成 > 同步服务](#连接与集成)。

### 桌面

仅桌面版。

**桌面窗口行为**

- 最小化到托盘：点最小化时收进系统托盘。
- 关闭窗口时隐藏到托盘：点关闭按钮时不退出，隐藏到托盘继续播放。
- 隐藏任务栏图标：主窗口开着也不在任务栏显示，主要通过系统托盘找回窗口。
- 隐藏全屏按钮：隐藏窗口控制按钮里的全屏切换按钮。
- 使用 macOS 原生全屏按钮：全屏按钮进入 macOS 原生全屏，而不是最大化窗口。
- 壁纸模式：把窗口沉到桌面最底层，作为常驻的歌词壁纸。进入前会确认一次；进入后窗口无法关闭、最小化或移动，**键盘不可用**，鼠标事件由 Folia 转发。要退出，在系统托盘（macOS 为菜单栏）的 Folia 菜单里再点一次`壁纸模式`，命令面板也能切换。
  - 壁纸显示器：有多块显示器时选壁纸用哪一块（`自动`、`主显示器`或具体某块）。
  - macOS 需要先在`系统设置 → 隐私与安全性 → 输入监控`中勾选 Folia 并重启应用，否则无法转发鼠标。
  - 自动隐藏 Dock 栏（macOS）：壁纸模式期间自动隐藏底部 Dock。
  - 配合 [播放页 > 底部组件高度](#播放页) 可以把进度条挪到合适的高度。

**Remote Control（遥控窗口）**

- 隐藏 Remote Control 任务栏图标：遥控窗打开时不在任务栏单独占一个图标。
- 隐藏 Remote Control 顶部悬浮栏：窗口顶部的透明区域仍可拖动来移动窗口；关闭窗口用托盘菜单里的`遥控窗口`，或命令面板的`切换遥控窗口`。
- Remote Control 点击穿透：解锁方法是托盘菜单的`解锁遥控窗口`、命令面板的`解锁远程控制`，或关掉这个开关。
- 展开封面：闲置时把封面展开成大图。

Folia 崩溃时会保存一份诊断日志；Windows 卸载程序可以选择是否一并清除用户数据。

### 性能与动效

**性能与背景**

- 静态模式：关闭几何背景以节省资源，不影响歌词文字动画。
- 关闭主页动态背景：主页不再播放背景动画，降低 GPU 占用。
- 开启播放页原生毛玻璃背景：改用系统原生毛玻璃，此时主题、图片和 Monet 等背景不再显示。只在桌面版的非透明模式下生效，移动窗口时可能卡顿。
- 实验性动画帧率限制：限制动画帧率，选一个限制档位。适合性能排查，但可能带来兼容问题。
- 后台节流（仅桌面版，默认关闭）：窗口最小化或隐藏到托盘时交给 Chromium 节流，歌词动画也停下，回来后从当前进度接着播；音乐照常播放。默认关闭是因为用 OBS 窗口采集直播时，窗口在后台也要照常画。壁纸模式、导出视频和 OBS 浏览器源连着时自动不生效。
- 修复 Linux 歌词动画卡死：改变部分歌词动画的发光绘制方式。Linux 下默认开启，详见 [Chromium FD 耗尽问题](/guide/chromium-fd-exhaustion)。
- 渲染显卡（仅 Windows 桌面版）：`自动`（由系统决定，笔记本上通常是核显，更省电）、`高性能`（独立显卡，更流畅更耗电）或`省电`（核显），重启后生效。在 Windows「图形设置」里给 Folia 单独指定过显卡时，以系统设置为准。

**降低动态效果**

Folia 默认播放完整动画，不会因为系统关掉了动画效果就把动效变成瞬移。这里可以逐项调低：`队列拼贴`、`混音过渡`、`歌单展开转场`、`Monet 背景漂移`、`界面微动效`、`设置页平滑滚动`；也可以打开`跟随系统设置`，由系统的动画设置决定全部动效。

## 高级

### 模组

仅桌面版。

- 模组系统：开启后才加载模组，并出现`模组`命令。模组以应用的完整权限运行，启用每个模组时仍要单独确认。关闭时不加载任何模组代码，已启用的模组也会停用。
- 模组管理：列出已安装的模组，并有[模组市场](https://folium-compound.cielaniska.top)的链接。

详见 [模组系统（Folium 1.7）](/guide/mods)。

### 开发者

- 运行日志：记录后台运行时的日志，渲染进程和主进程的都能在这里看到。
- 写入本地文件：把日志写到本地文件，可选`追加`或`覆盖`，并能打开日志文件夹。反馈问题时附上它最有用。
- 内存监控：按采样间隔定时记录各进程的内存与 CPU 占用。

## 建议的起手顺序

第一次接触 Folia，推荐按这个顺序设置：

1. 在 [快速开始](/guide/quick-start) 完成安装或部署。
2. 在 `界面 > 外观` 选一个喜欢的歌词动画和主题，在 `界面 > 主页与歌单` 选资料库界面。
3. 在 `音乐` 两页设置智能过渡、队列行为、响度平衡和歌词来源。
4. 桌面用户再看 `应用 > 桌面` 和 `应用 > 快捷操作`，决定是否用托盘、壁纸模式和全局快捷键。
5. 要直播或接外部程序时，看 `应用 > 连接与集成`；机器吃力时，看 `应用 > 性能与动效`。
