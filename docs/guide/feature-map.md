# 功能地图与 GUI 位置

> [!TIP]
> 使用 Bravais 新版资料库时，首页页签、搜索、账户和设置位于中央信息条，集合操作也在信息条内。详细位置与截图见 [Bravais 新版界面操作指南](/guide/bravais)。本页下方的主页顶部栏说明主要适用于经典网格。

这页专门给两类场景准备：

- 你想快速知道某个功能在界面的哪里。
- 你想让 AI 读取文档后，能准确定位 Folia 当前实现里的入口、开关和面板。

本文以主仓库 `folia-major` 当前 GUI 实现为准，优先描述“用户在屏幕上实际能看到和点到的东西”。

## 怎么看这页

- `主页 > 左上角 > 设置按钮` 表示从主页左上区域进入。
- `播放页 > 右侧面板 > 控制` 表示先打开播放页右侧面板，再切到 `控制` 标签。
- `设置 > 帮助` 与 `设置 > 选项` 指的是设置弹窗顶部的两个一级标签。
- `设置 > 界面 > 外观` 这类路径是 `选项` 标签下的分组和页面，`选项` 两个字省略不写。
- `桌面版专属` 表示 Web 版通常不会出现，或意义明显弱很多。

## 全局 GUI 总览

| 区域 | 你会看到什么 | 主要作用 |
| --- | --- | --- |
| 主页顶部左侧 | `Folia` 标题、设置/帮助按钮、扫描进度环 | 打开帮助与设置、查看本地曲库扫描状态 |
| 主页顶部中间 | 标签切换条 | 在 `歌单 / 电台 / 探索 / 专辑 / 本地 / Navidrome / 舞台` 之间切换 |
| 主页顶部右侧 | 搜索框 | 按当前标签搜索网易云、本地曲库或 Navidrome |
| 主内容区 | 海报墙、专辑墙、本地列表、Navidrome 视图 | 浏览和进入具体内容 |
| 播放页中央 | 歌词动画、封面、歌曲信息 | Folia 的核心沉浸式播放体验 |
| Lattice 队列拼贴 | 整条播放队列铺成的海报墙 | 与播放页并列的第二个播放视图，`Ctrl/Cmd + B` 开关 |
| 播放页底部 | 播放控制栏 | 播放、暂停、进度、音量 |
| 播放页右侧 | 右侧面板 | 主题、歌词、队列、账号、本地/服务器专属信息 |
| 设置弹窗 | `帮助 / 选项` 双页 | 帮助、快捷键、设置中心、实验功能 |
| 命令面板 | 任意界面按 `Ctrl/Cmd + K`；空闲区域也可按 `S` | 用命令直达页面、面板、设置和动作。在 Lattice 里它是主要操作方式 |
| 遥控窗 | `Folia Remote` 小窗，桌面版专属 | 不切回主窗口也能控制播放、录制和透明模式 |

## 主页

### 顶部栏

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 主页 > 左上角 > 设置图标 | 打开设置弹窗 | 默认先进入 `帮助` 页；有更新时按钮会带红点 |
| 主页 > 左上角 > 扫描进度环 | 查看本地扫描进度 | 仅在导入本地文件夹、后台提取元数据和封面时出现 |
| 主页 > 顶部中间 > 标签条 | 切换主页内容 | 默认包含 `歌单 / 电台 / 探索 / 专辑 / 本地`（可在 `设置 > 界面 > 主页与歌单` 隐藏）；启用 Navidrome 后会出现 `Navidrome`；启用舞台入口后会出现 `舞台` |
| 主页 > 右上角 > 搜索框 | 搜索当前来源 | 会随当前标签自动切换搜索对象 |

### 各主页标签

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 主页 > `歌单` | 浏览网易云歌单 | 未登录时会显示登录引导 |
| 主页 > `电台` | 进入私人 FM 与推荐歌单 | 属于网易云入口的一部分 |
| 主页 > `探索` | 各平台的推荐歌单、排行榜、新歌与新碟 | 还有最近播放和「再听一次」 |
| 主页 > `专辑` | 浏览喜欢的专辑 | 首次进入时会加载收藏专辑 |
| 主页 > `本地` | 进入本地音乐视图 | 管理文件夹、专辑、艺人、本地歌单 |
| 主页 > `Navidrome` | 进入 Navidrome 视图 | 需要先在 `设置 > 应用 > 连接与集成` 启用并配置；走 Subsonic / OpenSubsonic API |
| 主页 > `舞台` | 打开 Stage / Now Playing 播放页 | 只在相关能力启用后出现 |

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 海报墙或列表聚焦时直接键入 | 即时搜索 | 用户指引里也专门说明了这个行为 |

## 播放页

### 主界面

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 播放页中央 | 歌词动画显示 | 所有 visualizer 都在这里渲染 |
| 播放页中央/上方 | 当前歌曲标题、艺人、专辑 | 是用户识别当前歌曲的主信息区 |
| 播放页底部 | 播放控制栏 | 播放/暂停、上一首、下一首、进度、音量 |
| 播放页右缘 | 右侧面板开关 | 打开后可切换多个标签页 |

### 播放页快捷动作

| GUI 位置或方式 | 功能 | 说明 |
| --- | --- | --- |
| `Space` | 播放 / 暂停 | 帮助页和用户指引都有写 |
| `Ctrl + ←/→` 或 macOS `Cmd + ←/→` | 上一首 / 下一首 | 桌面端歌曲切换快捷键 |
| `←/→` | 快退 / 快进 5 秒 | 直接作用在当前播放 |
| `P` | 打开 / 关闭右侧面板 | 即使隐藏了右侧按钮，也还能这样打开 |
| `H` | 隐藏播放页控件 | 用户指引中列为播放器快捷键 |
| `F11` | 浏览器全屏 | Web 和桌面版都可作为显示层使用 |
| `Ctrl/Cmd + K` | 打开命令面板 | 全局入口，在任意界面可用 |
| `Ctrl/Cmd + P` | 打开队列界面 | 私人 FM 期间停用 |
| `Ctrl/Cmd + B` | 打开 / 退出 Lattice 队列拼贴 | 全局，私人 FM 期间停用 |
| `:` | 执行模式 | 再按一个字母立即执行命令 |
| `S` | 打开命令面板 | 焦点不在输入框时可用；首页网格默认优先把字符交给筛选 |

## 播放页右侧面板

### 固定标签

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 播放页 > 右侧面板 > `封面` | 歌曲信息页 | 点击歌手或专辑可跳转详情；点击标题可复制歌曲信息；如果是已匹配的网易云歌曲，`Ctrl+点击标题` 还能打开对应网易云歌曲页 |
| 播放页 > 右侧面板 > `控制` | 主题、循环、音量、动画模式 | 是播放页内最常用的视觉控制区 |
| 播放页 > 右侧面板 > `队列` | 当前播放队列 | 支持点击任意歌曲跳转播放、打乱队列、把当前队列保存为本地歌单 |
| 播放页 > 右侧面板 > `账号` | 网易云账号与同步 | 显示头像、昵称、会员状态、音质切换、同步数据、退出登录 |

### 按歌曲来源追加的标签

| GUI 位置 | 何时出现 | 功能 |
| --- | --- | --- |
| 播放页 > 右侧面板 > `本地` | 当前歌曲来自本地音乐 | 查看文件名、大小、比特率、歌词来源、ReplayGain；上传歌词文件；在线匹配歌词；切换 `本地 / 内嵌 / 在线` 歌词来源；调节歌词时间偏移 |
| 播放页 > 右侧面板 > `Navidrome` | 当前歌曲来自 Navidrome | 查看服务器歌曲 ID；在线匹配歌词；查看当前使用的是 `服务器歌词` 还是在线匹配结果；调节歌词时间偏移 |
| 播放页 > 右侧面板 > `歌词` | 当前歌曲来自网易云在线播放 | 导入歌词文件；重新在线匹配；在 `在线来源` 与 `导入文件` 之间切换；调节歌词时间偏移 |

### `控制` 标签里能做的事

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 右侧面板 > `控制` > 第一排按钮 | 循环、收藏、生成 AI 主题 | 分别对应循环模式切换、喜欢歌曲、为当前歌曲生成 AI 主题 |
| 右侧面板 > `控制` > 音量 | 调整当前播放器音量 | 包括静音切换 |
| 右侧面板 > `控制` > 音量行 > 效果器按钮 | 打开音频效果器 | 十段均衡器加后处理效果链，也可从命令面板打开 |
| 右侧面板 > `控制` > 动画模式 | 切换 visualizer | 可直接在这里切到 `流光 / 心象 / 云阶 / 浮名 / 莫奈 / 群唱 / 倾诉 / 回环 / 镜台 / 时计 / 商籁 / 凝彩 / 绘光 / 花火` 等模式 |
| 右侧面板 > `控制` > 动画强度 | 切换 `calm / normal / chaotic` | 是播放页内的快速强度开关，不等于完整调参 |
| 右侧面板 > `控制` > 背景 | 切换默认主题 / AI 主题 / 自定义主题 | 也可在这里快速切换明暗模式和封面主色参与背景 |

## 设置弹窗

设置弹窗顶部有两个一级标签：`帮助` 和 `选项`。

### 帮助页

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 设置 > `帮助` | 查看键盘快捷键 | 包含主页导航、播放控制等基础快捷键 |
| 设置 > `帮助` > `Show User Guide` | 打开用户指引 | 是一个多页引导，包含即时搜索、播放器快捷键、命令面板、主题说明 |
| 设置 > `帮助` > `Need help?` | 打开 AI 求助提示词弹窗 | 会生成一段附带文档站和 GitHub 仓库链接的提示词，方便复制到外部 AI 工具中求助 |
| 设置 > `帮助` > 底部版本行 | 复制版本信息 | 便于反馈问题时带上版本、分支和提交哈希 |

### 选项页总览

v0.7.21 起，`选项` 按 `界面 / 音乐 / 应用 / 高级` 四组排列；左侧导航上方有搜索框，能直接搜到页面里的单个选项。逐项说明见 [设置说明](/guide/settings)，旧版页面名对照见 [旧版设置去哪了](/guide/settings#旧版设置去哪了)。

| GUI 位置 | 功能 | 说明 |
| --- | --- | --- |
| 设置 > `选项` > `界面` > `外观` | 歌词动画、明暗模式、配色预设、主题乐园、歌曲主题、AI 主题设置 | AI 主题设置仅桌面版 |
| 设置 > `选项` > `界面` > `播放页` | 播放后进入的视图、Lattice 暗角与叠色、控制栏、歌曲信息卡片、视频层、隐藏播放页 UI | 进度条右侧两个按钮也在这里 |
| 设置 > `选项` > `界面` > `主页与歌单` | 资料库界面、Bravais 墙面、顶部胶囊入口、歌单卡片样式、网格卡片 | Bravais 墙面分组只在用 Bravais 时出现 |
| 设置 > `选项` > `音乐` > `播放控制` | 智能过渡、声卡、ReplayGain、淡入淡出、自动转换音频、队列默认位置、自动跳过 | 影响播放行为而不是视觉样式 |
| 设置 > `选项` > `音乐` > `歌词` | 歌词来源与优先级、全局时间偏移、歌词过滤、本地歌词格式优先级 | |
| 设置 > `选项` > `应用` > `通用` | 界面语言、启动与窗口、更新检查、思索教程提示 | 更新检查仅桌面版 |
| 设置 > `选项` > `应用` > `快捷操作` | 全局快捷键、快捷命令、`Alt + 字母` 自定义快捷键、海报墙手势与 S 键 | 全局快捷键仅桌面版 |
| 设置 > `选项` > `应用` > `连接与集成` | Navidrome、同步服务、Discord、听歌打卡、透明背景、OBS、歌词接口、舞台模式 | 所有对外连接入口都在这里 |
| 设置 > `选项` > `应用` > `存储与备份` | 媒体缓存与上限、缓存详情、本地文件夹监视、配置导入导出 | |
| 设置 > `选项` > `应用` > `桌面` | 托盘、全屏按钮、壁纸模式、遥控窗口 | 仅桌面版 |
| 设置 > `选项` > `应用` > `性能与动效` | 静态模式、帧率限制、原生毛玻璃、后台节流、渲染显卡、降低动态效果 | |
| 设置 > `选项` > `高级` > `模组` | 模组系统总开关、模组管理 | 仅桌面版，详见 [模组系统](/guide/mods) |
| 设置 > `选项` > `高级` > `开发者` | 运行日志、写入本地文件、内存监控 | 反馈问题时用得上 |

## 命令面板

命令面板是 Folia 的全局操作中枢。推荐在任意界面按 `Ctrl/Cmd + K` 打开；完整用法见[命令面板用户指南](/guide/command-palette)。

### 命令类型

| 命令类型 | 典型命令 |
| --- | --- |
| 搜索 | 搜当前音乐来源 / 本地 / Navidrome / 网易云、筛选当前视图 |
| 设置 | 打开帮助、打开选项、直达任意设置小节、语言切换、睡眠定时、立即同步 |
| 导航 | 回主页、回播放页、打开 Lattice、Lattice 聚焦当前歌曲、切到具体主页标签、浏览器全屏 |
| 面板 | 打开 `封面 / 控制 / 队列 / 账号 / 本地 / Navidrome / 歌词` 标签 |
| 播放 | 播放、暂停、上一首、下一首、循环、收藏、添加到歌单、静音、音量、打乱队列、清空队列、队列界面、匹配最佳歌词、私人 FM 模式 |
| 音频 | 音频效果器、均衡器预设、ReplayGain 模式、智能过渡与过渡模式 |
| 视觉 | 切换 visualizer、每首歌随机模式、切换背景模式（common / nomand / latent / sora / url / monet）、生成 AI 主题、主题快速编辑器、主题来源、歌词分词调整、透明背景、明暗切换 |
| 网格 | 排序、切换合集面板与曲目列表、重新导入文件夹、整理歌曲信息、导出歌单、实体编辑、编辑模式 |
| 桌面 | 切换歌词接口、遥控窗、主窗口置顶、壁纸模式、播放时阻止休眠、语音输入时暂停、模组 |

它还提供队列 `@artist` / `@album` 筛选和 `--remove` / `--next` / `--end` 批量操作、网格筛选的 `--play` / `--add`、`:` 执行模式、睡眠定时参数、歌词分词调整，以及最多三个固定命令。具体语法和快捷键以[命令面板用户指南](/guide/command-palette)为准。
