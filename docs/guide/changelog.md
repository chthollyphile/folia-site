## [v0.7.6](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.6) · 2026-09-08

- 点击播放后可选择进入可视化播放器或 Lattice 队列拼贴，并可随时在界面设置中修改；私人 FM 仍会使用标准播放器。

- 命令面板新增当前网格的排序、重新扫描、歌曲信息整理、歌单导出及编辑操作；设置命令现在可直达具体小节，网格筛选支持 `--play` 和 `--add`。

_命令面板可以按 ctrl/cmd + K 打开_

- 从本地音乐库移除子目录后，可持续忽略该目录而不影响整个根目录，并可从目录树中恢复和重新扫描。

- 海报墙新增设置选项，可以调节卡片样式

- 新增可选的网易云听歌打卡：仅针对已登录账号的在线网易云歌曲，真实播放满 30 秒后上传听歌历史到账户听歌打卡；本地文件、云盘歌曲和其他平台不会上报。此功能会主动上传账户听歌记录，用于网易云的推荐计算，有一定风险，请谨慎使用。

- 设置页面左侧导航改为默认展开，方便查找功能设置。

- macOS 与 Linux 现在也会检查新版本是否发布，但受平台限制，不支持自动更新，用户可手动下载完整安装包覆盖，或使用包管理器；桌面端新增崩溃诊断日志，Windows 卸载时可选择清除用户数据。
- Tempera 与 Sonnet 减少不必要的 GPU 纹理占用；修复 Monet、Lattice 标题裁切，并支持关闭底部后续歌词的模糊效果。
- 修复音频转码完成后自动播放可能无法继续、Theme Park 重置异常，以及模组导出与音频转码错误共用 FFmpeg 的问题。

## [v0.7.4](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.4) · 2026-09-06

- 队列拼贴视图（Lattice）

按下 Ctrl+B，或者从命令面板，顶部胶囊右侧按钮打开。把整个**播放队列**形成经典 Metro Design 风格的无限拼贴格子。可通过拖动或方向键浏览，回车展开歌曲、再按一次播放。

播放中的展开封面上会显示轻量版的 monet/莫奈 歌词动画。可开启切歌自动聚焦，并调整边缘暗角与海报叠色（支持自定义颜色与强度）。

私人 FM 模式下不可用。

- 兼容更多音频格式：桌面端内置 FFmpeg，之前因为解码问题无法播放的本地或 Navidrome 歌曲，现在会在播放器临时转化为兼容的无损格式进行播放，此转换不改动原文件。转换结果进入缓存目录，Automix 的节拍分析也会走转换后的音频，可在播放设置中关闭。

- macOS 壁纸模式：Mac 现在也能把 Folia 沉到桌面图标下方作为歌词壁纸，无需重启应用即可原地切换，并可选 择壁纸模式期间自动隐藏 Dock 栏。需要在「系统设置 → 隐私与安全性 → 输入监控」中授权 Folia 才能转发鼠标；该模式下键盘不可用。

- 本地文件夹自动扫描：开启后监视已导入的本地文件夹，文件增删改时自动做一次增量扫描，无需手动重新导入。默认关闭，可在存储设置中逐个文件夹查看监视状态并重新检查；部分环境只能监视文件夹本层。

- 保留歌词过滤表达式：关闭逐行歌词过滤不再清空写好的正则表达式，下次开启时仍在原处。
- Monet 可隐藏频谱：Monet 视觉器新增频谱显示开关
- 正在播放卡片现在也会出现在队列拼贴页面
- 改进了系统托盘右键菜单的功能
- 其他性能优化和修复

## [v0.7.1](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.1) · 2026-08-30

**Folia 0.7.1 — Pleiades Update**

Pleiades Update 是 Folia 迄今规模最大的播放体验更新之一，覆盖智能混音、模组扩展、Windows 桌面集成、睡眠定时、歌曲信息展示、Remote Control 与歌词视觉器。

#### Folia Automix 智能过渡

- 新增 Folia Automix，根据两首歌曲的节拍、速度、调性、响度、前奏、尾奏和段落结构自动规划切歌。
- Automix 会根据歌曲特征选择切拍、低频交接、尾奏承接或等功率淡化，不再局限于固定时长的 Crossfade。
- 支持速度对齐、频段交接、人声退场、回声收尾，以及更具冲击力的“表现模式”。
- 新增混音过渡动画；歌曲信息卡片显示时，过渡进度会沿卡片边框呈现。
- 桌面端可在设置中按需下载、扫描、安装、移除或迁移分析模型。
- 完整模型与运行时约 249 MB，用于更准确的节拍网格、音轨分离和表现模式；模型不再强制随安装包分发。
- 未安装模型时会进入兼容模式；Web 端或无法分析音频时会自动回退到稳定的 Crossfade。
- 在线歌曲需要开启歌曲缓存才能完成充分分析，否则 Automix 效果会受到明显影响。
- 修复混音期间暂停、拖动进度、手动切歌、Media Session 控制、Blob URL 回收和分轨缓存淘汰等边界问题。

#### Forge 式模组系统（实验性）

- 桌面端新增模组加载器，可从 `mods/` 目录发现和加载 Folia 模组。
- 在“设置 → 实验室”开启模组系统后，可通过命令面板进入模组管理界面。
- 支持将 `.zip` 模组包直接拖入面板完成安装或覆盖更新，并提供安全路径、文件数量、体积和 manifest 校验。
- 支持模组依赖、版本约束、生命周期清理、批量启用/禁用、运行日志和内容指纹校验。
- 模组文件发生变化后会自动撤销既有信任并保持禁用，需要重新确认后才能启用。
- 模组可以注册命令、提供自定义视觉器、读取播放状态，以及实现歌词动画视频导出等扩展能力。
- 模组系统默认关闭，单个模组也默认禁用。
- 模组不是安全沙箱：启用后会以应用完整权限运行。请仅安装和启用可信来源的模组。
- 当前 `apiVersion 1` 仍处于实验阶段，后续版本可能调整 API 与权限定义。

#### Windows 桌面壁纸模式

- Windows 现在可以将 Folia 窗口沉入桌面图标下方，作为常驻歌词壁纸。

- 支持从设置、系统托盘和命令面板切换壁纸模式。
- 新增桌面层挂载、鼠标事件转发、多显示器几何处理和桌面结构变化恢复。
- 当辅助进程、渲染器或桌面挂载连续异常时，会自动退出壁纸状态并恢复普通窗口，避免应用无法找回。
- Windows 壁纸模式下键盘输入不可用；窗口透明能力也会受到当前 Windows 桌面架构限制。

#### 睡眠定时

- 命令面板新增睡眠定时界面，可分别设置小时和分钟。
- 支持直接输入分钟数快速启动倒计时。
- 支持 `--on [time]` 和 `--off` 语法快速启用或取消定时器。
- 倒计时状态在应用重启后清空。
- 到时后桌面端自动退出 Folia；Web 端则暂停播放。
- 命令面板会实时显示剩余时间和当前启用状态。

#### 歌曲信息卡片与下一首预告

- 歌词页左下角新增可点击的歌曲信息卡片，显示封面、歌曲名和歌手。
- 卡片可设置为限时显示、常驻显示或完全隐藏，并可选择是否同时出现在首页。
- 点击首页卡片可进入播放页；点击播放页卡片可展开歌曲信息面板。
- 自动切歌前会切换为“接下来播放”状态，提前展示下一首歌曲。
- Automix 运行时，卡片会持续显示并承担混音进度动画。
- 卡片显示方式、显示时长和首页开关已纳入视觉配置导入与导出。

#### Remote Control 与切歌衔接

- Remote Control 新增单曲循环、列表循环和关闭循环的切换控制。
- 悬停上一首、下一首按钮时可以预览目标歌曲名称。
- Remote Control 现在按实际听到的 Automix/Crossfade 交接时刻更新歌曲、封面、进度和播放状态。
- 优化自动切歌期间的封面预加载、进度同步和歌曲切换动画。
- 修复封面 URL 失效或偶发加载失败时出现空白封面的问题。

#### 视觉器与播放体验改进

- 商籁 Sonnet 与凝彩 Tempera 新增平滑切歌过渡，避免换歌时画面大幅度跳变。
- 凝彩的切歌行为、文本测量缓存和场景计算得到优化，并修复亮色主题下自定义图片弹窗文字不可见的问题。
- 莫奈 Monet 新增封面交叉过渡，修复切歌时封面跳变和偶发加载失败。
- 优化时计 Pendolo 的几何体性能，减少高负载场景的资源占用。
- 本地音乐新增按专辑号排序，并按专辑实体正确分组；只有存在曲目编号时才显示编号标签。
- 音频缓存与封面缓存现在独立维护，减少封面缺失、重复下载和缓存回填异常。
- 系统托盘新增“重置窗口状态”，可快速解除透明、点击穿透和置顶状态。
- 点击穿透开启时会禁用无效的悬停交互，只保留用于解除锁定的入口。
- 修复 OBS 浏览器源配置复制、Now Playing 卡片位置、封面缓存和多个播放控制边界问题。
