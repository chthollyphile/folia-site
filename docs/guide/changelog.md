## [v0.7.22](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.22) · 2026-10-23

- **汽水音乐**：桌面版新增汽水音乐，用抖音扫码登录；支持搜索、播放（标准音质）、逐字歌词、自己的歌单和最近播放，推荐流和场景电台可以当私人 FM 听，能红心、在自建歌单里加歌删歌。没有可直接播放音源的歌放不了，暂不支持浏览专辑、新建歌单和收藏歌单。
- **新歌词样式「花火」**：日系歌词 PV 的画风，歌词带着色块逐字出场，烟花沿着字开花，镜头之间整个画面跟着升空的烟花旋转上升，副歌时亮起辉光；开了智能动感模式会随拍开花、推镜。
- **随机歌词样式可以自选范围**：勾选几种样式组成随机池，每首歌换一种，不连着重复；播放面板上能重抽一种，随机池会跟着导入导出和同步。

- **全局播放快捷键（桌面版）**：Folia 不在前台也能用 Ctrl+Alt+Shift（macOS 是 Control+Option+Shift）加一个键控制播放、音量、循环和随机，模组命令也能绑定；原生 Wayland 下一键注册到桌面环境。

- **AI 服务商与模型（桌面版）**：可以直接选 Gemini、DeepSeek、小米 MiMo、阿里云 Qwen、腾讯云 TokenHub、OpenAI、Anthropic、Kimi、智谱 GLM 或自定义接口，填好密钥就能从列表里选模型，思考、温度等参数按服务商自动处理。切歌后，上一首没生成完的 AI 主题不会再盖到这首上。
- 重启后各平台的登录不会再因为断网或服务器出错被清掉。
- 智能动感模式新增「只用已分析」一档，总开关挪到歌词样式窗口新的「全局」页。
- 本地和 Navidrome 的歌也会做自动混音的过渡分析；自动混音分离音轨时优先用显卡。
- 本地扫描支持 DSD（.dsf、.dff）。
- Windows 新增「渲染显卡」设置，可选自动、高性能或省电。「性能与动效」新增「后台节流」（默认关），窗口最小化或隐藏时停住歌词动画。

- QQ 音乐网络抖动时先重试，再退到试听；试听片段的歌词会对上片段的位置，Lattice 的歌词时间轴也按此高亮和跳转。
- Bravais：信息条方向可选自动、竖向或横向；探索墙放上了最近播放和再听一次；没连平台或曲库为空时，墙上会写一段说明。
- macOS 开着台前调度时，点壁纸上的控件不再把别的窗口拉到前面。
- Linux X11 下设置 `FOLIA_LINUX_VULKAN=1` 可以打开 Vulkan，让智能动感模式用上 WebGPU。
- Docker：`OPENAI_API_MODEL` 留空时不再默认填入固定模型。
- 模组接口升级到 Folium 1.7。

## [v0.7.21](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.21) · 2026-10-18

**0.7.21「Sabbat-of-the-witch Update」重大更新**

- 桌面版新增 Spotify 和 YouTube Music。Spotify 在系统浏览器里授权登录，播放需要 Spotify 会员（最高 320k，Intel Mac 暂不能播放）。YouTube Music 不登录也能搜索和播放，登录要用本机的 Chrome、Edge、Chromium 或 Brave。网页版暂不提供这两个平台。
- 统一登录窗口：网易云、QQ 音乐、酷狗、波点、Spotify、YouTube Music 都在同一个窗口里登录、切换和退出，出错时会说明原因和多久后可以重试。
- 主页新增「探索」页签：网易云、QQ 音乐、Spotify、YouTube Music 的推荐歌单、排行榜、新歌和新碟，以及最近播放和「再听一次」。Bravais 也有探索页签，从探索页打开 Lattice 会铺成一面海报墙。
- 智能动感模式（桌面版，需要 WebGPU）：商籁、镜台跟着节拍动，时计跟着分离出的鼓声动，每个效果可以单独开关、调强度。用到的模型随安装包附带，自动混音也不用再单独下载模型。
- QQ 音乐：支持 QQ 音乐 App 扫码登录，网页版连 Serverless 后端时登录自动续期，最长 30 天。登录后搜歌更稳定。新增音乐云盘、会员等级、歌单播放数和新建空歌单，拿不到完整音源时会改播试听片段并提示。这些需要后端升级到 qq-music-api 3.3.3。
- 界面可以切换成繁体中文；设置页重新分成界面、音乐、应用、高级四组，同步设置挪到「连接与集成」。
- 新增「空闲时隐藏鼠标指针」和「定位正在播放的歌」；遥控窗口重新设计，可以关掉闲置时的大封面；自动混音过渡时，莫奈和遥控窗口会跟着混音换歌。
- 多显示器下可以选择壁纸模式用哪块屏，Windows 壁纸模式拖动更跟手，别的窗口里拖动不再平移壁纸。
- 新增 Linux ARM64 安装包；模组接口升级到 Folium 1.6。
- 修复：Windows 上 TEMP 环境变量没展开时启动崩溃；透明播放窗口的圆角对齐系统，全屏时不再露出桌面；纯 Wayland 下置顶开关改为置灰，不再假装已置顶；单曲循环播完一遍的歌也会进缓存；进入壁纸模式前先确认一次。

## [v0.7.20](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.20) · 2026-10-15

- QQ 音乐功能补全：登录后有每日推荐、私人 FM 和推荐歌单（推荐歌单不登录也能看）；可以红心歌曲、收藏歌单和专辑，往自己创建的歌单里加歌删歌。播放失败时如果可能是会员或地区限制，会给出提示。QQ 暂不支持「不喜欢」。
- 新增「无法播放时自动跳过」（默认关闭）：需要会员或购买、只能试听、地区不可播放或原因不明的歌曲会倒计时跳到下一首。需要登录的歌曲和网络问题不会跳过。
- 视频导出更可靠：边录边写入磁盘，4K 等大文件不再在最后一步失败；Linux（包括 Wayland）下不再找不到录制源，4K 录制帧率明显提升；导出的 MP4 能正确显示时长。
- Intel Mac（macOS 13 及以上）也能使用自动混音的人声分离。
- 模组（Folium 1.5）：可以在首页添加自己的页面，可以控制音量、静音、循环模式和播放队列，也能感知播放失败。模组面板显示占用空间，可以清空缓存；模组设置的下拉框和 Folia 其它地方样式一致；「先行测试」渠道的模组用紫色标记，启用前会提示风险。
- 其它修复：Bravais 首页的设置格会提示新版本；Bravais 首页搜索不再显示空结果，也不再搜错平台；修复部分 Linux 发行版上竖排中文标签叠在一起；海报翻走时不再闪回默认配色；桌面版加强了外部链接和内部通信的安全检查，AI 密钥只会发往保存时的地址。

## [v0.7.19](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.19) · 2026-10-13

- **Bravais 歌手页变成海报**：完整信息条画成一张凝彩风格的海报，钉在墙的左边，配色取自歌手最热门的三张专辑；右边的专辑墙随之倾斜，倾斜着也能拖动和滚动。

- **专辑页海报与封面拼贴**：专辑页换成贴着封面、带立体标题的海报，并有入场动画；从歌手页点开专辑时封面会飞到海报上，返回时飞回原位。整张专辑同一张封面时，旁边的曲目墙会拼成一整张大封面。

- **播放失败会说明原因**：在线歌曲播放失败不再一律显示「歌曲已下架」，会区分下架、断网或超时、服务异常、需要登录 / 会员 / 购买、地区限制等情况。只有真正下架时才自动跳到下一首；断网时保留队列，可以重试或跳过。网易云、QQ 音乐、酷狗、波点均已支持。
- **中文、日文歌词分词更自然**：凝彩、商籁等按词排版的模式改用新的默认分词 icu-folia，中文不再被切碎，日文按文节切分；你手动保存的分词仍然优先。
- **网页版断网也能启动**：修复网页版 / PWA 断网后刷新打不开的问题，本地封面离线时也能正常显示；主题图标改为按需加载，启动时下载的内容更少。
- 修复 Android 上打开设置等覆盖层时闪出底下墙面的问题。
- 修复凝彩播放时调整窗口大小偶尔崩溃的问题。
- Sora 背景在暂停时停止绘制，静态模式下星点定格。
- 启动时弹出的版本更新窗口可以按 Esc 关闭。

## [v0.7.18](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.18) · 2026-10-11

- 直接管理播放队列：在 Bravais 或 Lattice 的「墙面工具」里点「播放队列」，即可点歌播放（不跳页）、拖动排序、下一首播放 / 移到末尾 / 移除、存为本地歌单或清空，支持键盘操作。私人 FM 下不可用，外部舞台播放时只能点歌。

- Bravais 与 Lattice 的墙面工具统一为同一套布局：顶部六个快捷格，下面是音量、墙面外观、海报叠色与灯光，面板更紧凑。

- 歌词可视化更省资源：商籁、凝彩、绘光、心象、回环、莫奈、时计与 Latent 背景等模式减少每帧重复计算；时计齿轮装饰改用 WebGL2 绘制，调商籁设置不再重建画布，切换模式时及时释放图形上下文。
- 本地歌曲连续播放时切歌不再卡顿，曲库较大时切歌也更快。
- QQ 扫码因登录设备已满失败时，会直接说明原因并给出清理设备的步骤，不再误报为网络问题（网页版目前仅能识别微信扫码的这种情况）。
- 桌面版 AI 密钥（Gemini / OpenAI）改用系统安全存储加密保存，旧版明文会自动迁移；保存后不再回显，清除改为单独按钮。
- 设置里的版本信息会标出自部署（Docker、Vercel、Cloudflare）与非官方构建；网页版部署问题会提示联系部署者。
- 修复：「下一首播放」在当前歌位于队尾时落错位置；Wayland 下锁定窗口后悬停解锁按钮闪动、点不到；商籁弧形仪表多出一圈亮环。

## [v0.7.1](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.1) · 2026-08-30

**Folia 0.7.1 — Pleiades Update**

Pleiades Update 是 Folia 迄今规模最大的播放体验更新之一，覆盖智能混音、模组扩展、Windows 桌面集成、睡眠定时、歌曲信息展示、Remote Control 与歌词视觉器。

#### Folia Automix 智能过渡

- 新增 Folia Automix，根据两首歌曲的节拍、速度、调性、响度、前奏、尾奏和段落结构自动规划切歌。
- Automix 会根据歌曲特征选择切拍、低频交接、尾奏承接或等功率淡化，不再局限于固定时长的 Crossfade。
- 支持速度对齐、频段交接、人声退场、回声收尾，以及更具冲击力的“表现模式”。
- 新增混音过渡动画；歌曲信息卡片显示时，过渡进度会沿卡片边框呈现。
- 桌面端可在设置中按需下载、扫描、安装、移除或迁移分析模型。
- 完整模型与运行时约 249 MB，用于更准确的节拍网格、音轨分离和表现模式；模型不再强制随安装包分发。
- 未安装模型时会进入兼容模式；Web 端或无法分析音频时会自动回退到稳定的 Crossfade。
- 在线歌曲需要开启歌曲缓存才能完成充分分析，否则 Automix 效果会受到明显影响。
- 修复混音期间暂停、拖动进度、手动切歌、Media Session 控制、Blob URL 回收和分轨缓存淘汰等边界问题。

#### Forge 式模组系统（实验性）

- 桌面端新增模组加载器，可从 `mods/` 目录发现和加载 Folia 模组。
- 在“设置 → 实验室”开启模组系统后，可通过命令面板进入模组管理界面。
- 支持将 `.zip` 模组包直接拖入面板完成安装或覆盖更新，并提供安全路径、文件数量、体积和 manifest 校验。
- 支持模组依赖、版本约束、生命周期清理、批量启用/禁用、运行日志和内容指纹校验。
- 模组文件发生变化后会自动撤销既有信任并保持禁用，需要重新确认后才能启用。
- 模组可以注册命令、提供自定义视觉器、读取播放状态，以及实现歌词动画视频导出等扩展能力。
- 模组系统默认关闭，单个模组也默认禁用。
- 模组不是安全沙箱：启用后会以应用完整权限运行。请仅安装和启用可信来源的模组。
- 当前 `apiVersion 1` 仍处于实验阶段，后续版本可能调整 API 与权限定义。

#### Windows 桌面壁纸模式

- Windows 现在可以将 Folia 窗口沉入桌面图标下方，作为常驻歌词壁纸。

- 支持从设置、系统托盘和命令面板切换壁纸模式。
- 新增桌面层挂载、鼠标事件转发、多显示器几何处理和桌面结构变化恢复。
- 当辅助进程、渲染器或桌面挂载连续异常时，会自动退出壁纸状态并恢复普通窗口，避免应用无法找回。
- Windows 壁纸模式下键盘输入不可用；窗口透明能力也会受到当前 Windows 桌面架构限制。

#### 睡眠定时

- 命令面板新增睡眠定时界面，可分别设置小时和分钟。
- 支持直接输入分钟数快速启动倒计时。
- 支持 `--on [time]` 和 `--off` 语法快速启用或取消定时器。
- 倒计时状态在应用重启后清空。
- 到时后桌面端自动退出 Folia；Web 端则暂停播放。
- 命令面板会实时显示剩余时间和当前启用状态。

#### 歌曲信息卡片与下一首预告

- 歌词页左下角新增可点击的歌曲信息卡片，显示封面、歌曲名和歌手。
- 卡片可设置为限时显示、常驻显示或完全隐藏，并可选择是否同时出现在首页。
- 点击首页卡片可进入播放页；点击播放页卡片可展开歌曲信息面板。
- 自动切歌前会切换为“接下来播放”状态，提前展示下一首歌曲。
- Automix 运行时，卡片会持续显示并承担混音进度动画。
- 卡片显示方式、显示时长和首页开关已纳入视觉配置导入与导出。

#### Remote Control 与切歌衔接

- Remote Control 新增单曲循环、列表循环和关闭循环的切换控制。
- 悬停上一首、下一首按钮时可以预览目标歌曲名称。
- Remote Control 现在按实际听到的 Automix/Crossfade 交接时刻更新歌曲、封面、进度和播放状态。
- 优化自动切歌期间的封面预加载、进度同步和歌曲切换动画。
- 修复封面 URL 失效或偶发加载失败时出现空白封面的问题。

#### 视觉器与播放体验改进

- 商籁 Sonnet 与凝彩 Tempera 新增平滑切歌过渡，避免换歌时画面大幅度跳变。
- 凝彩的切歌行为、文本测量缓存和场景计算得到优化，并修复亮色主题下自定义图片弹窗文字不可见的问题。
- 莫奈 Monet 新增封面交叉过渡，修复切歌时封面跳变和偶发加载失败。
- 优化时计 Pendolo 的几何体性能，减少高负载场景的资源占用。

- **新功能：自定义视频导出分辨率**。在遥控面板中，新增自定义视频导出宽度与高度输入，支持将自定义分辨率保存至预设中，并提供一键将播放器主窗口缩放至对应预设尺寸的操作
- **新功能：远程控制收藏按钮**。在远程控制界面中新增收藏按钮，方便一键收藏或取消收藏当前歌曲

#### 歌词与可视化
- **新功能：“莫奈”/Monet 歌词**。加入了 Folia 风格的平面排版设计的传统形态的音乐播放器歌词界面
- **新功能：“莫奈”/Monet 背景**。适配“莫奈”的图片型背景，支持半屏融合/全屏叠色两种预设，可设置模糊，叠色，重着色等多种图片效果，并可支持自定义背景图。
- 修复 “群唱” 特效的配置持久化异常。移除了在自定义表情包未加载完成时误将其重置为内置表情包的逻辑

#### 设置与选项
- 修复配色主题面板调色时窗口意外关闭的问题。
- **新功能：主题分享**：在视觉设置中新增了分享与导入主题的功能。可以将自己喜欢的配色主题一键复制，分享给其他用户

#### 本地音乐与导入
- Electron 客户端新增对系统目录及常用用户目录的导入拦截，防止用户误导入受限目录，并弹出对话框提示重新选择文件夹
- 在导入本地音乐文件夹时，若遇到受限或无法读取的子目录及文件，将自动跳过并记录警告，不再中断整个扫描与导入流程；同时，仅在成功扫描后才持久化目录句柄，避免写入无效配置

## [v0.4.17](https://github.com/chthollyphile/folia-major/releases/tag/v0.4.17) · 2026-06-05

#### 命令面板
- 新功能：命令面板。在播放页面按下 `S` 键，或向左滑动右下角控制按钮以打开。
- 支持搜索歌曲与各种命令操作，可直接控制播放、切换各种可视化歌词动画、调整窗口背景与日夜模式，以及快速直达各个设置子面板

#### 设置与同步
- 数据同步功能新增登录状态失效检测，并会重新获取歌单数据，防止因为登录状态失效而导致歌单显示错误

#### 歌词与动画
- “流光” 歌词效果现在支持自适应排版和旧版排版模式的切换，并增加了单词间距调节选项
- 优化了 “群唱” 歌词动画，修复了连续短歌词时的发言者轮换逻辑，微调了字级展现时间
- 修复了 “群唱” 对尺寸测量使用时间偏移以解决气泡长度与歌词长度不匹配的问题，使歌词同步表现更精准

#### 界面与交互
- 优化了浅色模式下标题栏按钮的对比度，显著提高了按钮的可读性与易用性
- 修复了移动端设备下右侧按钮在交互后的 hover 状态残留和可能导致的误触问题
- 在线歌词状态按钮样式微调

## [v0.4.16](https://github.com/chthollyphile/folia-major/releases/tag/v0.4.16) · 2026-06-03

#### 歌词动画
- 全新歌词动画设置页面，从一处即可调整所有播放页面的视觉设置
- 在线歌曲现在也可以强制重新匹配歌词，或使用本地上传的lrc歌词文件了
- 点击控制面板封面页面的歌曲名称，可以一键复制歌曲的摘要信息（格式为 `歌名 - 歌手 - 专辑`）及网易云链接到剪贴板，按 `Ctrl + 左键` 可直接在浏览器中打开网易云对应网页
- “流光” 现在可以调整是否开启字符旋转以及呼吸动画了
- “群唱” 现在支持任意数量的自定义表情，并且可以上传使用自定义头像了

#### 遥控窗口
- 遥控窗口现在会在鼠标移出的时候展示当前歌词
-  新增了置顶主窗口的功能，可以设置将主窗口放置于桌面顶部，请搭配点击穿透使用
- 主窗口处于透明播放页状态时，标题栏区域新增了阴影填充，方便用户移动窗口
- 修复了一个导致遥控窗口的进度条点击之后无反应的问题

#### 播放器
- 新增 全局动画帧率限制器 (FPS Limiter)，可将软件内部动态效果的最大帧速率锁定在 `60 FPS`、`90 FPS`、`120 FPS` 从而大幅度降低软件在高刷新率屏幕上的资源消耗。此功能为实验性功能，可能存在一些意料之外的问题，请谨慎使用。
