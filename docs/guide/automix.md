# Folia 智能过渡（Automix）

Folia 的切歌过渡有两档：固定时长的交叉淡化，和会分析两首歌再决定怎么接的 Automix。

设置位置：`设置 > 音乐 > 播放控制 > Folia 智能过渡`
命令面板：搜索`智能过渡`、`过渡模式`

## 两种过渡模式

| 模式 | 做法 | 适合 |
| --- | --- | --- |
| Folia Crossfade | 固定的淡出淡入，时长可调 | 任何环境，永远可用 |
| Folia Automix | 分析两首歌的节拍、速度、调性、响度、前奏、尾奏和段落结构，再决定这一次怎么接 | 桌面端，或能解码音频做分析的环境 |

Automix 会根据歌曲特征在几种接法里选择：切拍、低频交接、尾奏承接、等功率淡化，而不是固定套一个淡化曲线。它还支持速度对齐、频段交接、人声退场和回声收尾。

`过渡最长时长`只在 `Folia Crossfade` 模式下出现，决定固定淡化的时长上限。Automix 自己决定每一次的过渡长度。

## 完全体与兼容模式

Automix 有两档引擎：

| 引擎 | 条件 | 差别 |
| --- | --- | --- |
| 完全体 | 桌面端（模型随安装包附带） | 更精准的节拍网格与音轨拆分 |
| 兼容模式 | 运行在浏览器里 | 受浏览器端技术限制，混音效果明显弱一些 |

当前环境完全无法解码音频做分析时，Automix 不可用，切歌会退回稳定的交叉淡化，设置页会明确写出这一点。

### 分析模型

从 v0.7.21 起，分析模型随桌面版安装包附带，不用再单独下载：

| 模型 | 作用范围 |
| --- | --- |
| Beat This! | Automix 的节拍网格 |
| HTDemucs | 人声 / 音轨分离，表现模式依赖它 |

智能动感模式和 Automix 共用同一个分析服务，一首歌第一次播放时先分析一会儿，之后会记住结果。旧版本单独下载过的模型已经用不到，Folia 会提示是否清理。

部分设备的处理器无法运行人声分离，这类设备上用不了依赖它的功能。

## 表现模式

`表现模式`提供更激进的过渡表现，要求：

- 桌面端
- 设备能运行音轨分离（HTDemucs）

浏览器端受技术限制无法开启。

## 过渡动画

`过渡动画`把这次混音画出来，三选一：

| 选项 | 表现 |
| --- | --- |
| 已关闭 | 不显示 |
| 屏幕圆环 | 画在屏幕正中央，按任意键消失 |
| 卡片描边 | 画在歌曲信息卡片的边框上，只在卡片在场时出现 |

短于 5 秒的过渡不显示动画。

## 在线歌曲需要开启歌曲缓存

Automix 必须提前拿到完整音频才能分析。在线歌曲如果没有缓存，就来不及分析：

`设置 > 应用 > 存储与备份 > 媒体缓存 > 缓存歌曲`

设置页在检测到缓存关闭时会直接提示，并给一个`开启歌曲缓存`的快捷按钮。缓存关闭时，Automix 对在线歌曲的实际效果会明显下降。

本地音乐和 Navidrome 歌曲不受这一条影响。桌面端做过转码回退的歌曲，节拍分析会走转换后的音频。

## 命令面板入口

| 命令 | 作用 |
| --- | --- |
| 智能过渡 | 总开关 |
| 过渡模式：Folia Crossfade | 切到固定淡化 |
| 过渡模式：Folia Automix | 切到自动混音 |
| 过渡表现模式 | 切换表现模式（需要模型） |
| 智能过渡（设置） | 直接跳到这一小节的设置 |

## 常见问题

### 切歌时什么都没发生

先确认`过渡`总开关是开的。另外，手动切歌时过渡可能来不及展开——它是为自动衔接到下一首设计的。

### 一直显示“已退回淡化”

说明这一次没能完成分析。常见原因：在线歌曲没有缓存、模型未安装、当前环境无法解码音频。

### 设置里没有“表现模式”开关，或它是灰的

它需要桌面端加上已安装的人声分离模型。模型下载完成后开关会自动可用，不需要重启。
