# Lattice（队列拼贴）

Lattice 是 Folia 的第二个播放界面。它把**整条播放队列**铺成一面无限延伸的海报墙，用经典 Metro Design 风格的拼贴格子展示每一首歌，正在播放的那首会被放大并叠上走字歌词。

它和播放页是并列关系，不是播放页的一个子面板：

| | 播放页（可视化） | Lattice（队列拼贴） |
| --- | --- | --- |
| 关注点 | 当前这一首 | 整条队列 |
| 画面主体 | 歌词动画 + 背景 | 海报墙 + 展开卡片上的轻量歌词 |
| 侧边面板 | 有（封面 / 控制 / 队列 / 账号…） | 无，改用命令面板 |
| 歌词动画模式 | 13 种可选 | 固定使用轻量版莫奈 |
| 私人 FM | 支持 | 不支持 |

::: tip 在 Lattice 里，命令面板就是操作面板
Lattice 只负责“显示队列”，它自己不提供播放设置、主题、歌词来源这些入口，也从不修改队列。所有这类操作都走命令面板。好消息是 Lattice 里没有任何东西抢键盘输入，所以单键 <kbd>S</kbd> 和 <kbd>:</kbd> 在这里都能直接用——比在海报墙上更顺手。详见[命令面板](/guide/command-palette)。
:::

## 打开与退出

| 方式 | 说明 |
| --- | --- |
| <kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd> | 全局开关。在任意界面按下进入 Lattice，在 Lattice 里再按一次退出 |
| 命令面板搜索 `Lattice` / `队列拼贴` | 对应命令 `Lattice 打开` |
| 执行模式 <kbd>:</kbd> 然后 <kbd>W</kbd> | 最快的键盘入口。注意这个键只用于**进入**，Lattice 里不再提供 |
| 进度条右侧按钮 | 把某个槽位设成`歌曲墙`后，点它即可进入 |
| 点击播放后自动进入 | 见下方“把 Lattice 设为播放入口” |

退出的方式：<kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd>、<kbd>Esc</kbd>（连续按到没有选中项为止），或左上角的返回箭头。退出会回到你进来之前的那个页面，没有历史记录时回首页。

### 把 Lattice 设为播放入口

从 v0.7.6 起，点击播放后进入哪个视图是可选的：

`设置 > 选项 > 界面设置 > 播放后进入的视图`

- `可视化`：进入播放页，多种歌词动画和背景搭配（默认）。
- `Lattice（队列拼贴）`：整条播放队列铺成海报墙，正在播放的那首会被放大。

首次使用时 Folia 会主动询问一次，选过之后就不再问，随时可以回设置里改。命令面板里也有 `播放后进入：可视化` 和 `播放后进入：Lattice` 两条命令可以直接切换。

### 私人 FM 下不可用

私人 FM 自己接管队列，而 Lattice 的每一个操作最终都落在“播放队列里的某一首”上，两者不兼容。所以：

- 私人 FM 播放期间，`Lattice 打开` 命令不可用。
- 如果你把播放入口设成了 Lattice，启动私人 FM 时仍然会进入标准播放器，并在屏幕上方给出一条说明提示。

## 海报墙怎么读

- 每一块海报对应队列里的一首歌，**顺序就是队列顺序**。
- 海报角标上的编号是它在队列中的位置（从 1 开始）。
- 队列被分成三段：已播放、正在播放、待播放。正在播放的那一首会带`正在播放`标记。
- 队列为空时，墙上会显示提示：开始播放任意歌曲后，队列就会在这里铺开。

Lattice 是纯展示层：它读取队列并渲染，从不改动队列内容。想增删、排序、批量移动，用命令面板的队列命令（见下文）。

## 浏览与操作

### 鼠标 / 触摸

| 动作 | 效果 |
| --- | --- |
| 按住拖动空白处 | 平移整面墙 |
| 单击一块海报 | 展开它 |
| 再次点击已展开的海报 | 显示 / 隐藏播放控制条 |
| 悬停海报 | 海报轻微浮起 |

拖动过程中松手不会误触发展开——Lattice 会区分“拖了一下”和“点了一下”。

### 键盘

| 按键 | 效果 |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | 在相邻海报之间移动选中。第一次按只是接管屏幕上已有的选中位置，之后才开始真正移动 |
| <kbd>Enter</kbd> | 未展开时展开选中海报；已展开时播放它。如果它就是当前歌曲，则切换播放 / 暂停 |
| <kbd>Space</kbd> | 未展开时展开；已展开时显示 / 隐藏播放控制条 |
| <kbd>Esc</kbd> | 先收起展开的海报和选中状态，再按一次才退出 Lattice |
| <kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd> | 直接退出 Lattice |

选中会随着移动自动把镜头平移过去，不需要自己拖。

### 展开后的卡片

展开的海报会露出一条播放控制条，和播放页底部用的是同一套控件：

- 播放 / 暂停按钮：当前歌曲就切换播放，其他歌曲则从这里开始播放。
- 上一首 / 下一首，中间两个按钮是**你在设置里配置的进度条槽位**（`设置 > 选项 > 界面设置 > 底部界面 > 进度条按钮槽位`），可选循环、收藏、队列、音量、歌词时间轴、睡眠定时等。
- 时间显示与可拖动的进度条。
- 右上角的斜箭头：切到播放页看完整歌词动画。

如果展开的正是**当前正在播放**的歌曲，封面上还会叠一层轻量版的莫奈歌词动画，跟着音乐走字。

## 工具面板

Lattice 右下角有一个独立的工具按钮（齿轮图标），点开是 Lattice 专属的小面板：

| 条目 | 作用 | 快捷方式 |
| --- | --- | --- |
| 聚焦当前歌曲 | 把正在播放的海报拉回屏幕中央 | <kbd>:</kbd> 然后 <kbd>C</kbd> |
| 切歌时自动聚焦 | 开关：换歌时自动把新歌拉回中央 | — |
| 打开队列命令 | 直接打开命令面板的队列界面 | <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd> |
| 开灯 / 关灯 | 切换海报灯光。关灯后，除正在播放的那张之外的所有海报都会被一层遮罩盖住（暗色下压暗、亮色下压白），画面只剩当前这一张 | — |
| 操作提示（问号） | 展开一份最小的按键速查 | — |

这个按钮支持滑动手势：**向左滑动可直接打开命令面板**，和海报墙上的操作按钮是同一套交互。

## 外观设置

`设置 > 选项 > 视觉设置 > 队列拼贴设置`

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| 边缘暗角 | 在页面四周加一层淡暗角，让视线落在中间的海报上 | 开 |
| 海报聚焦叠色 | 给普通海报加一层颜色叠层，突出正在播放、选中或悬停的海报 | 开 |
| 强制使用自定义颜色 | 用固定颜色替换由当前主题生成的渐变叠色 | 关 |
| 叠层颜色 | 自定义叠色的颜色 | `#161419` |
| 叠色强度 | 叠层的浓淡，0–1 | 0.5 |

命令面板里也能直接调这几项：

- `Lattice 边缘暗角`
- `Lattice 自动聚焦`
- `Lattice 海报叠色`（打开后可在面板内直接调颜色和强度）

“海报灯光（开灯 / 关灯）”和“切歌时自动聚焦”这两项在工具面板里，改动会被记住。

## 在 Lattice 里用命令面板

这是 Lattice 的推荐操作方式。Lattice 没有侧边面板，但命令面板是全局的，能覆盖几乎所有操作。

在 Lattice 里，下面这些入口全部可用，而且因为墙上没有筛选输入框抢键盘，**单键入口也不会被吞掉**：

| 按键 | 打开什么 |
| --- | --- |
| <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd> | 完整命令面板 |
| <kbd>S</kbd> | 完整命令面板（不需要额外开关，海报墙上才需要） |
| <kbd>:</kbd> | 执行模式，再按一个字母立即执行 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd> | 直接进入队列界面 |

几条在 Lattice 里最常用的：

| 目的 | 怎么做 |
| --- | --- |
| 增删、排序、批量移动队列歌曲 | <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd>，用 `@artist:` / `@album:` 筛选，再加 `--remove` / `--next` / `--end` |
| 把当前歌曲拉回中央 | <kbd>:</kbd> <kbd>C</kbd> |
| 回到播放页 | 命令面板搜索`回到播放器`，或点展开卡片右上角的斜箭头 |
| 退出 Lattice | <kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd>、<kbd>Esc</kbd>，或左上角返回箭头 |
| 调音量 | <kbd>:</kbd> <kbd>V</kbd> |
| 切换明暗 | <kbd>:</kbd> <kbd>D</kbd> |
| 打开设置 | <kbd>:</kbd> <kbd>O</kbd> |
| 打开配色编辑器 | <kbd>:</kbd> <kbd>T</kbd> |

::: warning 注意 `C` 的含义会变
执行模式的 <kbd>C</kbd> 在播放页是`打开封面面板`，在 Lattice 里是`聚焦当前歌曲`。两个界面不可能同时存在，所以它们共用了同一个键。
:::

完整的命令列表、`--` 选项语法和自定义快捷键见[命令面板](/guide/command-palette)。

## 常见问题

### 按 Ctrl/Cmd + B 没反应

先确认焦点不在输入框里。另外，如果当前正在播放私人 FM，`Lattice 打开` 会被停用——退出私人 FM 后再试。

### 展开的海报上没有歌词

轻量歌词只画在**当前正在播放**的那首歌的展开卡片上。展开队列里的其他歌曲只会看到封面和播放控制条。

### 队列很长时会卡吗

墙会做可视区域剔除，只渲染屏幕附近的海报。如果仍然吃力，可以：

- 在视觉设置里关掉`边缘暗角`和`海报聚焦叠色`。
- 在实验室里打开`实验性动画帧率限制`。

### 想从 Lattice 里删歌

Lattice 本身不改队列。按 <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd> 进队列界面，搜索或筛选后追加 `--remove`。

### 首页的海报墙和 Lattice 是一回事吗

不是。首页的网格展示的是歌单 / 专辑 / 本地曲库的内容，支持直接键入筛选；Lattice 展示的是**当前播放队列**。两者的卡片样式设置也是分开的（`网格卡片` vs `队列拼贴设置`）。
