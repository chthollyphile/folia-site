# 命令面板

命令面板是 Folia 的全局操作入口。它不只是一个命令搜索框：它还能搜索歌曲、筛选当前网格、管理播放队列、调音量、挑歌词动画、改设置，并把一部分功能的完整交互界面直接开在面板里。

本文按 `folia-major v0.7.6` 的实现编写。

::: tip 在 Lattice（队列拼贴）里，命令面板就是主操作方式
Lattice 没有侧边面板，本身也只负责显示队列、从不修改队列。所有操作——排队列、调音量、换主题、回播放页——都通过命令面板完成。而且 Lattice 里没有任何组件抢占键盘输入，单键 <kbd>S</kbd> 和 <kbd>:</kbd> 在那里可以直接用。详见 [Lattice（队列拼贴）](/guide/lattice)。
:::

## 打开命令面板

| 方式 | 作用 | 适用范围 |
| --- | --- | --- |
| <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>K</kbd> | 打开完整命令面板 | 全局，任何界面、任何焦点状态都有效 |
| <kbd>S</kbd> | 打开完整命令面板 | 焦点不在输入框，且当前界面没有“直接键入筛选”的网格时 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd> | 直接进入队列界面 | 非私人 FM 模式 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd> | 筛选当前视图 | 首页网格等支持筛选的页面 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd> | 打开 / 退出 Lattice | 全局，直接执行，不停留在面板 |
| <kbd>:</kbd> | 进入执行模式 | 焦点不在输入框，且当前界面没有筛选网格时 |
| <kbd>Alt</kbd> + 字母 | 执行你自己绑定的命令 | 全局，需先在交互控制里录制 |

最稳妥的入口是 <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd>：它带修饰键，永远不会和搜索框、中文输入法或网格的“直接键入以筛选”冲突。

### 各入口的优先级

多个入口可能同时想要同一次按键，Folia 的判定顺序是固定的：

1. 你的自定义 <kbd>Alt</kbd> + 字母快捷键。
2. <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd>。
3. **正在读取键入内容的界面**（首页网格的即时筛选）——它会拿走所有不带修饰键的字符。
4. 各命令自己声明的入口快捷键（<kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd>、<kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd>、<kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd>、<kbd>:</kbd>）。
5. 裸 <kbd>S</kbd>。

带修饰键的入口在第 3 步之前就被处理掉，所以它们在任何界面都能用；不带修饰键的入口（<kbd>S</kbd>、<kbd>:</kbd>）只在没有筛选网格接管键盘时才生效。

### 为什么在首页海报墙按 S 有时不会打开

首页网格会把单字符输入直接当成筛选内容，<kbd>S</kbd> 也不例外。若希望它在网格上也打开命令面板：

`设置 > 选项 > 交互控制 > 海报墙上用 S 键打开命令窗口`

开启后，网格上的 <kbd>S</kbd> 改为打开命令面板，其他字符仍进筛选框。焦点位于输入框、文本框、下拉框或可编辑区域时，裸按 <kbd>S</kbd> 一律不触发。

这个限制**只存在于首页网格**。播放页和 Lattice 里没有筛选输入，<kbd>S</kbd> 直接可用。

## 查找与执行命令

打开后直接输入你想做的事。检索支持：

- **中文、英文和拼音**：输入 `主题`、`theme` 或 `zhuti` 都能找到配色相关命令。中文界面下英文命令名同样可以搜到。
- **拼音首字母**：两个字母起就能命中，例如 `qkdl` → `清空队列`。首字母碰撞率高，所以它排在同档匹配的最后。
- **模糊匹配**：不必完整输入命令名，字母顺序对上即可，但它排在所有精确匹配之后。
- **排序加权**：最近用过的命令优先（记忆最近 10 条），此外还有一份使用频次统计给常用命令加成，14 天减半，几周不用就会让位给新习惯。
- **可用性过滤**：命令按当前平台、当前界面和当前播放状态自动隐藏或停用。

结果列表一次最多显示 10 条。输入为空时，面板会展示最近用过的命令和一组默认落地命令。

### 面板内的按键

| 操作 | 按键 |
| --- | --- |
| 选择上一项 / 下一项 | <kbd>↑</kbd> / <kbd>↓</kbd> |
| 执行当前项 | <kbd>Enter</kbd> |
| 补全 `--` 选项或 `@` 筛选建议 | <kbd>Tab</kbd> 或 <kbd>Enter</kbd> |
| 返回上一层 / 关闭 | <kbd>Esc</kbd> |
| 查看当前可用的全部命令 | 点输入框右侧的问号按钮 |

部分命令执行后立刻关闭面板；另一部分会先进入自己的操作界面（见下方“带界面的命令”）。

### 命令为什么会消失

命令的可见性由三个独立的条件决定：

| 维度 | 含义 | 例子 |
| --- | --- | --- |
| 平台 | 哪个版本带这个功能 | 遥控窗、壁纸模式、歌词接口只在桌面版出现 |
| 界面范围 | 需要什么样的环境 | 面板类命令要求在播放页；筛选命令要求当前有可筛选的网格；`Lattice 聚焦当前歌曲` 只在 Lattice 里出现；网格操作命令只在对应网格里出现 |
| 当前状态 | 现在做这件事有没有意义 | 私人 FM 播放时队列命令停用；没有当前歌曲时收藏、生成主题等命令不出现 |

想确认某条命令为什么找不到，先点问号看“全部命令”列表——那里只列当前真正可用的命令。

## 命令分类

面板里的命令按组归类，组名会显示在结果行上：

| 组 | 能做什么 |
| --- | --- |
| 搜索 | 搜索当前来源 / 本地 / Navidrome / 网易云；筛选当前视图 |
| 导航 | 回首页、回播放器、打开 Lattice、Lattice 聚焦当前歌曲、切换首页标签（歌单 / 本地 / 专辑 / Navidrome / 电台）、浏览器全屏、遥控窗、主窗口置顶 |
| 面板 | 打开播放页右侧面板的 `封面 / 控制 / 队列 / 账号 / 本地 / Navidrome / 歌词` 标签；模组管理面板也归在这一组 |
| 播放 | 播放、暂停、上一首、下一首、循环、收藏、添加到歌单、静音、音量、打乱队列、清空队列、队列界面、匹配最佳歌词、音频效果器与音效预设、ReplayGain 模式、私人 FM 模式 |
| 可视化 | 选择歌词动画、选择背景、每首歌随机模式、生成 AI 主题、快速主题编辑器、主题来源、歌词分词调整、透明背景、明暗切换 |
| 网格 | 当前网格的排序、面板开关、重新导入、整理歌曲信息、导出歌单、实体编辑、编辑模式 |
| 设置 | 打开设置的具体小节、快捷命令、自定义快捷键、语言、睡眠定时、同步、各类开关 |

### 设置命令可以直达小节

`设置` 组里除了`打开选项`这样的整页入口，还有一批直接跳到某一小节的命令，例如：

`歌词渲染方式`、`预设配色`、`网格卡片样式`、`队列行为`、`网易云听歌打卡`、`音频输出`、`智能过渡`、`Navidrome 服务器`、`Stage 模式`、`媒体缓存`、`同步服务设置`、`本地文件夹监视设置`、`固定命令槽位`、`自定义快捷键`、`海报墙操作按钮`、`播放后进入的视图`、`首页标签显示`、`调整底部控制条位置`、`进度条按钮槽位`。

执行后会打开设置弹窗并滚动到对应位置，不用自己在设置页里找。

### 网格操作命令（v0.7.6 起）

站在首页的本地曲库、专辑、歌单等网格上时，这一组命令会出现，把原本只在按钮和下拉菜单里的操作搬到键盘上：

| 命令 | 作用 |
| --- | --- |
| 按文件名排序 / 按修改时间排序 / 按音轨号排序 | 本地曲目的三种排序方式 |
| 反转排序方向 | 正序与倒序切换 |
| 切换合集面板 / 切换曲目列表 | 显示或隐藏网格旁的两个面板 |
| 重新导入此文件夹 / 重新导入全部文件夹 | 重新扫描并刷新曲库 |
| 整理歌曲信息 | 整理这个文件夹里歌曲的标题、艺人和专辑 |
| 导出此歌单 | 把本地歌单保存为 m3u8 |
| 编辑此专辑或艺人 | 打开本地曲库的实体编辑面板 |
| 切换编辑模式 | 进入 / 退出可从合集移除歌曲的模式 |

这些命令都没有分配执行模式单键：重新导入和整理信息会读盘、走网络，不适合一键触发。

## 带界面的命令

有些命令执行后不会立刻关闭面板，而是在面板里打开自己的交互界面：

| 命令 | 面板里会出现什么 |
| --- | --- |
| 队列 | 队列搜索列表，支持 `@` 筛选和 `--` 批量操作 |
| 音量条 | 可拖动的音量条，也可直接输入 0–100 |
| 睡眠定时 | 小时 / 分钟选择器与倒计时状态 |
| 私人 FM 模式 | 模式与场景列表，点一下直接切换 |
| 选择可视化 / 选择背景 | 带说明的动画模式与背景列表 |
| 歌词分词调整 | 当前歌曲的逐行分词编辑器 |
| 筛选当前视图 | 内嵌的筛选输入框 |
| 网格卡片外观 | 全画幅封面、方形卡片、远近缩放与淡出的滑块 |
| Lattice 海报叠色 | 叠色开关、颜色与强度控件 |
| 模组（实验性） | 模组管理面板 |
| 执行模式 | 当前可用的单键列表 |

在这些界面里按 <kbd>Esc</kbd> 会先退回命令列表，再按一次才关闭面板。

## 队列搜索与批量操作

按 <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd>，或在命令面板中搜索`队列`。这是在 Lattice 下管理队列的唯一途径，也是播放页最快的队列入口。

### 搜索与筛选

- 直接输入歌名、歌手、专辑或队列序号。
- 输入 <kbd>@</kbd> 查看可用的歌手与专辑建议。
- `@artist:歌手` 只看指定歌手。
- `@album:专辑` 只看指定专辑。
- 名称带空格时用双引号，例如 `@artist:"The Beatles"`。
- 只输入 `@` 时，优先匹配与当前歌曲相同的歌手或专辑。

### 批量操作

先输入搜索词或 `@` 筛选，再加上下列选项：

| 选项 | 别名 | 作用 |
| --- | --- | --- |
| `--remove` | `--rm`、`--delete` | 从队列移除所有匹配歌曲 |
| `--next` | | 把所有匹配歌曲移到下一首 |
| `--end` | | 把所有匹配歌曲移到队尾 |

例如：

```text
@artist:"The Beatles" --next
live --remove
@album:专辑名 --end
```

规则：

- 选项写在开头或结尾都可以，不用重排已经输入的内容。
- 批量操作必须带有实际搜索词或筛选条件，空条件不会执行。
- 执行前面板会显示将影响多少首歌，并要求确认。
- 当前正在播放的歌曲会被自动排除。
- 按 <kbd>Esc</kbd> 会先逐层清除批量动作、再清除筛选，最后才关闭面板。

## `--` 选项语法

进入支持参数的命令后，输入 `--` 就会列出该命令当前可用的选项。用方向键选择，再按 <kbd>Tab</kbd> 或 <kbd>Enter</kbd> 补全。

选项 token 可以放在输入的开头或结尾，Folia 会把它从筛选文本里剥掉再匹配。

### 睡眠定时

搜索`睡眠定时`后可以直接选小时和分钟，也可以输入：

```text
30
--on
--off
```

| 输入 | 作用 |
| --- | --- |
| `30` | 开启 30 分钟倒计时 |
| `--on`（别名 `--enable`） | 用界面里已设置的时长开启倒计时 |
| `--off`（别名 `--disable`） | 取消倒计时 |

桌面版倒计时结束后退出应用，Web 版则暂停播放。倒计时可以跨重启恢复。

### 网格筛选（v0.7.6 起）

<kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd> 打开的筛选框现在也能收尾，不用再回去点按钮：

| 选项 | 别名 | 作用 |
| --- | --- | --- |
| `--play` | `--p` | 立即播放筛选出的歌曲 |
| `--add` | `--queue`、`--a` | 把筛选出的歌曲追加到队列 |

这两项就是合集面板上的那两个按钮，作用对象同样是**筛选后的结果**而非整个合集。

### 歌词分词调整

当前歌词动画使用逐词排版时，搜索`歌词分词调整`可以手动修正分词，也可使用：

| 选项 | 别名 | 作用 |
| --- | --- | --- |
| `--ai` | `--segment` | 用已配置的模型重新分词 |
| `--copy-seg` | `--copy-segmentation`、`--copy-current` | 复制当前分词结果 |
| `--copy-prompt` | `--prompt` | 复制提示词和歌词，到外部模型里处理 |

AI 分词会调用你配置的模型、可能产生费用，因此它没有分配执行模式单键。

## 执行模式

按 <kbd>:</kbd> 进入执行模式，再按注册过的键，命令立刻执行，不需要 <kbd>Enter</kbd>。

| 键 | 命令 | 键 | 命令 |
| --- | --- | --- | --- |
| `q` | 队列 | `v` | 音量条 |
| `f` | 搜索当前来源 | `a` | 匹配最佳歌词 |
| `n` | 下一首 | `b` | 上一首 |
| `l` | 切换循环 | `r` | 打乱队列 |
| `e` | 音频效果器 | `m` | 选择可视化 |
| `g` | 选择背景 | `w` | Lattice 打开 |
| `h` | 打开帮助 | `o` | 打开选项 |
| `t` | 配色（Theme Park） | `d` | 切换明暗 |
| `c` | 播放页：面板 · 封面<br>Lattice：聚焦当前歌曲 | | |

关于这些键：

- 只有安全、可逆、不需要确认的命令才会分配单键。删除、重扫、AI 调用一律不给。
- `w` 只用于**进入** Lattice；已经在 Lattice 里时这条命令不再提供，退出用 <kbd>Ctrl/Cmd</kbd> + <kbd>B</kbd> 或 <kbd>Esc</kbd>。
- **同一界面内的键保证互不为前缀**，所以按够了就会立即触发，不需要等待判定。
- `c` 在播放页和 Lattice 里含义不同——这两个界面不可能同时存在，因此允许共用一个键。
- 执行模式只列出当前环境可用的键。
- 输入了无效字符时，先按 <kbd>Esc</kbd> 清空，再按一次 <kbd>Esc</kbd> 关闭。

## 固定命令与自定义快捷键

| 设置项 | 位置 | 说明 |
| --- | --- | --- |
| 快捷命令 | `设置 > 选项 > 界面设置` | 最多选三个命令，固定显示在命令面板底部，点一下直接执行。命令面板搜索`固定命令槽位`可直达 |
| 自定义快捷键 | `设置 > 选项 > 交互控制` | 选一个字母 + 一个全局命令，之后用 <kbd>Alt</kbd> + 该字母直接执行 |
| 海报墙上用 S 键打开命令窗口 | `设置 > 选项 > 交互控制` | 决定首页网格上的 <kbd>S</kbd> 是筛选还是开面板 |
| 海报墙操作按钮 | `设置 > 选项 > 交互控制` | 决定右下角按钮向左滑动时打开`过滤搜索`还是`命令窗口`；点击仍打开歌曲列表 |

自定义快捷键的限制：

- 只支持 <kbd>Alt</kbd> + `A–Z`，<kbd>Alt</kbd> 那一半是固定的。
- 只列出**在任何界面都能执行**的命令——那些只在播放页或某个网格里才有意义的命令不会出现在候选里。
- 与系统或 Folia 已占用的按键冲突时会被直接拒绝。

## 常见问题

### 输入命令后没有结果

点问号看当前可用的完整命令列表。部分命令只在桌面端、播放页、Lattice、支持筛选的网格，或有当前歌曲时才出现。

### S 键没有反应，或者打开了筛选

用 <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd>。如果只在首页网格上出现这个情况，检查`交互控制`里的“海报墙上用 S 键打开命令窗口”。

### Ctrl/Cmd + P 没有打开队列

私人 FM 接管队列时，队列命令会暂时停用——它的每个操作最终都会把你从电台流里带出去。退出私人 FM 后再试。

### Ctrl/Cmd + F 找不到

它只在“有东西可筛选”的界面出现。播放页和 Lattice 里没有可筛选的网格，所以这条命令不会列出。

### 中文输入法的第一个字母没有进入筛选框

这是网格“直接键入筛选”与输入法组合输入之间的兼容处理：面板会先接管输入焦点，让后续组合文本正常落入。开头那一次按键会被丢弃，而不是塞进输入框——否则会在输入法的候选前面留下一个多余的字母。也可以先用 <kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd> 打开筛选框再输入。
