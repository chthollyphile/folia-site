# 命令面板

命令面板是 Folia 的全局操作入口。它不仅能搜索命令，还能直接搜索歌曲、筛选当前海报墙、管理播放队列、调节音量，以及打开带交互界面的功能。

本文按 `folia-major v0.7.3` 的当前实现编写。

## 打开命令面板

| 方式 | 作用 | 适用范围 |
| --- | --- | --- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | 打开完整命令面板 | Windows / Linux，全局可用 |
| <kbd>Cmd</kbd> + <kbd>K</kbd> | 打开完整命令面板 | macOS，全局可用 |
| <kbd>S</kbd> | 打开完整命令面板 | 当前焦点不在输入框时可用；海报墙上的行为见下方说明 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd> | 直接打开队列 | 非私人 FM 模式 |
| <kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd> | 筛选当前视图 | 海报墙等支持筛选的页面 |
| <kbd>:</kbd> | 进入执行模式 | 当前焦点不在输入框、也不在海报墙筛选状态时 |

最稳妥的入口是 <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd>：它带修饰键，不会和搜索框、中文输入法或海报墙的“直接键入以筛选”冲突。

### 为什么在海报墙按 S 有时不会打开

海报墙会把单字符输入直接交给筛选框，因此默认情况下，<kbd>S</kbd> 也被当作筛选内容。若希望它始终打开命令面板，前往：

`设置 > 选项 > 交互控制 > 海报墙上用 S 键打开命令窗口`

开启后，海报墙上的 <kbd>S</kbd> 改为打开命令面板，其他字符仍用于筛选。焦点位于输入框、文本框、下拉框或可编辑区域时，裸按 <kbd>S</kbd> 不会触发命令面板。

## 查找与执行命令

打开后直接输入你想做的事。命令面板支持：

- 中文、英文和拼音，例如输入`主题`、`theme`或`zhuti`。
- 模糊匹配，不必完整输入命令名。
- 按使用频率和最近使用情况调整常用命令的排序。
- 按当前平台、页面和播放状态隐藏或停用不适用的命令。

常用操作：

| 操作 | 按键 |
| --- | --- |
| 选择上一项 / 下一项 | <kbd>↑</kbd> / <kbd>↓</kbd> |
| 执行当前项 | <kbd>Enter</kbd> |
| 接受 `--` 选项或队列筛选建议 | <kbd>Tab</kbd> 或 <kbd>Enter</kbd> |
| 返回上一层或关闭 | <kbd>Esc</kbd> |
| 查看所有当前可用命令 | 点击输入框右侧的问号按钮 |

某些命令执行后会立即关闭；搜索、队列、音量、可视化、背景、私人 FM、睡眠定时和歌词分词等命令会先进入自己的操作界面。

## 常用命令类型

| 类型 | 可以完成的操作 |
| --- | --- |
| 搜索与筛选 | 搜索当前音乐来源；筛选当前海报墙 |
| 导航 | 回首页或播放页；打开歌单、本地、专辑、Navidrome、电台；切换全屏 |
| 播放 | 播放、暂停、上一首、下一首、循环、收藏、静音、打乱或清空队列、添加到歌单、匹配最佳歌词 |
| 队列 | 搜索并播放队列歌曲；按歌手或专辑筛选；批量移除或移动歌曲 |
| 声音 | 设置音量；打开效果器；切换 ReplayGain 和音效预设 |
| 视觉 | 选择歌词动画和背景；切换明暗、透明背景；生成或编辑主题；调整歌词分词 |
| 设置与工具 | 打开具体设置页、用户指引、睡眠定时和同步功能 |
| 桌面端 | 遥控窗、窗口置顶、歌词接口、壁纸模式、阻止休眠等桌面能力 |

命令会根据环境动态变化。例如，桌面端专属命令不会出现在 Web 版；只作用于播放页侧栏的命令不会在无关页面显示；私人 FM 播放时会隐藏会破坏 FM 队列的操作。

## 队列搜索与批量操作

按 <kbd>Ctrl/Cmd</kbd> + <kbd>P</kbd>，或在命令面板中搜索`队列`，即可进入队列界面。

### 搜索与筛选

- 直接输入歌名、歌手、专辑或队列序号。
- 输入 <kbd>@</kbd> 查看可用的歌手与专辑建议。
- 使用 `@artist:歌手` 只看指定歌手。
- 使用 `@album:专辑` 只看指定专辑。
- 名称带空格时可以使用双引号，例如 `@artist:"The Beatles"`。
- 只输入 `@` 时，会优先匹配与当前歌曲相同的歌手或专辑。

### 批量操作

先输入搜索词或 `@` 筛选，再追加下列选项：

| 选项 | 作用 |
| --- | --- |
| `--remove` | 从队列移除所有匹配歌曲，也可写 `--rm` 或 `--delete` |
| `--next` | 把所有匹配歌曲移到下一首 |
| `--end` | 把所有匹配歌曲移到队尾 |

例如：

```text
@artist:"The Beatles" --next
live --remove
@album:专辑名 --end
```

批量操作必须带有实际搜索词或筛选条件，执行前会显示影响数量；当前正在播放的歌曲会被排除。按 <kbd>Esc</kbd> 会先逐层清除批量动作或未完成的筛选，再关闭面板。

## 使用 `--` 命令选项

进入支持参数的命令后，输入 `--` 就会列出该命令当前可用的选项。用方向键选择，再按 <kbd>Tab</kbd> 或 <kbd>Enter</kbd> 补全。

目前常见的带参数命令包括：

### 睡眠定时

搜索`睡眠定时`后可以直接选择小时和分钟，也可以输入：

```text
30
--on
--off
```

- `30`：开启 30 分钟倒计时。
- `--on`：使用界面里已设置的时长开启倒计时。
- `--off`：取消倒计时。
- 桌面版倒计时结束后退出应用，Web 版则暂停播放。

### 歌词分词调整

当当前歌词动画使用逐词排版时，搜索`歌词分词调整`可以手动修正分词，也可使用：

| 选项 | 作用 |
| --- | --- |
| `--ai` | 用已配置的模型重新分词，也可写 `--segment` |
| `--copy-seg` | 复制当前分词结果 |
| `--copy-prompt` | 复制提示词和歌词，到外部模型中处理 |

AI 分词会调用你配置的模型，可能产生费用，因此没有分配“一键立即执行”的快捷键。

## 执行模式

按 <kbd>:</kbd> 会打开执行模式。随后按一个已注册字母，命令会立刻执行，不需要再按 <kbd>Enter</kbd>。

| 字母 | 命令 | 字母 | 命令 |
| --- | --- | --- | --- |
| `q` | 队列 | `v` | 音量 |
| `f` | 搜索当前来源 | `a` | 匹配最佳歌词 |
| `n` | 下一首 | `b` | 上一首 |
| `l` | 切换循环 | `r` | 打乱队列 |
| `e` | 音频效果器 | `c` | 封面面板 |
| `m` | 选择歌词动画 | `g` | 选择背景 |
| `h` | 帮助 | `o` | 选项 |
| `t` | Theme Park | `d` | 切换明暗模式 |

执行模式只列出当前环境可用的快捷命令。若已经输入了无效字符，先按 <kbd>Esc</kbd> 清空，再按一次 <kbd>Esc</kbd> 关闭。

## 固定命令与自定义快捷键

前往 `设置 > 选项 > 交互控制`：

- `快捷命令`：最多选择三个命令，固定显示在命令面板底部。
- `自定义快捷键`：选择一个字母和一个全局命令，之后用 <kbd>Alt</kbd> + 该字母直接执行。
- `向左滑动打开`：决定海报墙右下角按钮的滑动手势打开筛选还是命令面板；点击仍然打开歌曲列表。

自定义快捷键只支持 `A–Z`，并只列出能在任何界面执行的命令。与系统或 Folia 已占用快捷键冲突的字母会被拒绝。

## 常见问题

### 输入命令后没有结果

先点击问号查看当前可用的完整命令列表。部分命令只在桌面端、播放页、支持筛选的海报墙，或有当前歌曲时出现。

### S 键没有反应或打开了筛选

使用 <kbd>Ctrl/Cmd</kbd> + <kbd>K</kbd>。若只在海报墙出现这个情况，请检查`交互控制`里的“海报墙上用 S 键打开命令窗口”。

### Ctrl/Cmd + P 没有打开队列

私人 FM 接管队列时，队列命令会暂时不可用。退出私人 FM 后再试。

### 中文输入法的第一个字母没有进入筛选框

这是海报墙直接键入筛选与输入法组合输入之间的兼容处理。面板会先接管输入焦点，让后续组合文本正常进入；也可以先用 <kbd>Ctrl/Cmd</kbd> + <kbd>F</kbd> 打开筛选框再输入。
