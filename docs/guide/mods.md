# 模组系统（Folium 1.7）

Folium 是 Folia 桌面版的模组平台。模组可以添加歌词动画和背景、扩展播放页与进度条、在首页加自己的页面、注册命令和设置，也可以控制播放与播放队列、读取在线音源和均衡器，或通过 Node 入口使用 ffmpeg 等本地能力。网页版和 PWA 不支持模组。

Folia v0.7.22 带的是 Folium 1.7。模组市场里标着需要更高 Folia 版本的模组，请先把 Folia 更新到对应版本。

想制作模组，请从[第一个模组：从零到跑起来](/developer/folium-quickstart)和[完整开发与贡献指南](/developer/folium-contributing)开始；接口细节见 [Folium 规范](/developer/folium-spec)和 [API 参考](/developer/folium-api)。

::: danger 启用前请确认来源
模组以可信代码运行，并非沙箱。`client` 入口可以访问主界面，`main` 入口拥有完整 Node.js 权限。清单里的权限声明不是安全边界。模组系统默认关闭，每个模组也默认禁用；启用时会出现原生确认窗口。请只启用你信任来源的模组。
:::

::: warning 开发与上架边界
Folium 1.7 的稳定接口包括 UI 扩展、歌词解析、播放控制与播放队列、首页页面、登录状态、只读的在线音源（`folium.omni`）、均衡器、密钥类设置和可绑定全局快捷键的命令。其他部分，尤其是 Omni provider 接口和平台后端直通 `platform.raw`，仍属实验接口，尚不具备应用内置 Omni provider 的对等能力。在 Folium v2 发布前，请绝对不要尝试制作超出当前实验接口能力的完整音源模组；接口缺口必然导致问题，浪费开发者和维护者的时间。

任何尝试导出 provider 的原始音频流或解密之后的原始音频文件的模组，都有极高的平台法律风险。无论采用何种实现方式，此类模组都不会上架官方模组市场。
:::

## 开启和安装

1. 在「设置 → 高级 → 模组」里打开「模组系统」总开关。
2. 在命令面板执行「模组」，打开管理面板。
3. 从[官方模组市场](https://folium-compound.cielaniska.top)下载模组 zip，拖入面板安装；也可以点击「打开模组目录」，手动放入模组。
4. 在面板中启用模组，并阅读原生确认窗口里的入口、权限、实验接口、签名与文件位置后确认。

关闭总开关会停用已启用的模组，停止加载模组代码。安装 zip 时会检查清单与入口文件，拒绝不安全路径。压缩包和解压后内容各不能超过 64 MB，单文件不能超过 32 MB，条目不能超过 2000；安装失败时保留旧版本。同 id 的 zip 可以覆盖安装，但内容变化后需要重新确认。

## 签名与文件变动

模组市场收录官方模组和通过审查的社区模组，均带 Folium 签名。签名用于识别审查过的文件内容，启用时仍需确认。

| 面板状态 | 含义 |
| --- | --- |
| 官方认证 | 签名有效，文件未在签名后改变（绿色盾牌） |
| 先行测试 | 签名有效，但来自先行测试渠道：只通过了安全审查，不保证功能可用（紫色烧瓶）；启用前会提示风险 |
| 未验证 | 没有官方签名；仍可安装和启用 |
| 签名不匹配 | 有签名，但校验失败，例如文件在签名后被修改；会显示警告（黄色盾牌） |

启用确认与模组目录的文件内容绑定。文件发生变化后，Folia 会撤销确认并禁用模组；检查变化后，在面板中重新启用并确认。开发版中放在主仓库 `mods/` 目录下的模组有专门的调试豁免，详情见[调试循环](/developer/folium-contributing#调试循环)。

## 模组用到的几项宿主功能

- **数据与缓存**：声明了数据目录的模组，在面板里展开它的那一行能看到「数据」「缓存」占用，并可以「清空缓存」。
- **全局快捷键**：模组可以提供能绑定成系统级快捷键的命令，在「设置 → 应用 → 快捷操作 → 全局快捷键」的命令下拉框里选用（原生 Wayland 下暂不提供）。
- **替换播放队列**：有 `playback.queue` 权限的模组可以一次换掉整个播放队列。替换后会提示是哪个模组换的，可以点「撤销」，提示条被顶掉后也能在命令面板执行「撤销模组替换的队列」。
- **均衡器**：模组可以切换音效或施加自己的均衡器曲线；想回到自己的设置，在命令面板执行「音效：换回我的音效」。
- **密钥设置**：模组设置里的密钥字段（如 API key）单独加密保存，界面上只显示是否已设置。
- **开销与安全启动**：面板里每个运行中的模组都写着启动耗时和运行开销，慢的会标出来。上次启动没完成（例如被某个模组卡住）时，下次打开会先问这次要不要不带模组启动。

## 透明歌词视频导出

导出类模组可调用宿主的视频导出服务，输出当前歌曲的歌词动画。需要安装完整的 ffmpeg；Folia 自带的 `ffmpeg-audio/` 只用于音频转码，不能用于视频导出。查找顺序为 `FOLIA_FFMPEG_PATH`、应用目录下的 `ffmpeg-8.1.2/ffmpeg(.exe)`、打包资源目录下的 `ffmpeg/ffmpeg(.exe)`、系统 PATH。

导出文件保存到「视频/Folia Exports」。当前上限为 3840×2160、60 fps、15 分钟，同时只能运行一个导出任务。透明通道在 Windows 上完整支持；Linux 和 macOS 的输出可能不含 Alpha，此时导出结果会给出警告。

## 常见问题

**找不到「模组」命令？** 先确认桌面版「设置 → 高级 → 模组」里的「模组系统」已开启。

**模组安装后没有出现功能？** 安装后仍是禁用状态。到面板中单独启用并确认；如果加载失败，查看面板显示的错误。

**改过模组文件后突然被禁用？** 内容变化会撤销上次确认。检查文件来源与改动后重新启用。

**如何发布到官方模组市场？** 阅读[开发与贡献指南的发布流程](/developer/folium-contributing#_6-发布到模组市场)。
